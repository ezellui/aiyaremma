Основные компоненты решения включают:

  1. Новые таблицы в базе данных:

    • category_templates - для хранения шаблонов категорий

    • Коллекция GeneratedElements в MongoDB для временного хранения новых элементов

  2. Сервис валидации элементов (ElementValidationService), который:

    • Проверяет наличие категорий и типов связей в базе
    • Сохраняет информацию о новых элементах
    • Управляет процессом одобрения

    • После получения графа от Claude происходит валидация
    • Новые элементы помечаются для одобрения
    • Пользователь получает уведомление о необходимости одобрения

  4. UI компонент NewElementsApproval для:

    • Просмотра новых элементов
    • Редактирования определений
    • Одобрения или отклонения элементов

  5. Интеграция с существующими сервисами:

    • Graph Service
    • Synthesis Service
    • Claude Service

Этот функционал обеспечит автоматическое расширение базы знаний системы новыми философскими категориями и типами связей, предложенными Claude, с контролем качества через процесс одобрения пользователем.
