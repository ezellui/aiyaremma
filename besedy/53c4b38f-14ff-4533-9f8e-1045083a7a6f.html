Инструкция по развертыванию философского граф-редактора на Windows 7

Этот проект представляет собой веб-приложение на базе React, позволяющее визуально создавать и редактировать философские концепции в виде графа. Ниже приведена пошаговая инструкция по настройке и запуску этого приложения на Windows 7.

Предварительные требования

  1. Node.js и npm - среда для запуска JavaScript-приложений
  2. Текстовый редактор - Visual Studio Code, Notepad++ или другой
  3. Командная строка - PowerShell или CMD
  4. Веб-браузер - Chrome, Firefox или Edge

Шаг 1: Установка Node.js

  1. Откройте браузер и перейдите на сайт: https://nodejs.org/

  2. Скачайте версию Node.js, совместимую с Windows 7 (рекомендуется версия 13.14.0 или более ранняя)

  3. Запустите скачанный файл установки (.msi)

  4. Следуйте инструкциям мастера установки:

    • Примите условия лицензионного соглашения
    • Выберите путь установки (можно оставить по умолчанию)
    • Нажмите "Установить"
    • Дождитесь завершения установки и нажмите "Готово"

  5. Проверьте установку, открыв командную строку (нажмите Win+R, введите cmd и нажмите Enter)

  6. Введите следующие команды:

    node -v
npm -v

    Вы должны увидеть версии установленных программ

Шаг 2: Создание проекта React

  1. Откройте командную строку (Win+R → cmd → Enter)
  2. Перейдите в каталог, где хотите создать проект:
    cd C:\Users\[Имя_пользователя]\Documents
  3. Создайте новый React проект:
    npx create-react-app philosophy-graph
  4. После завершения создания проекта перейдите в его каталог:
    cd philosophy-graph

Шаг 3: Установка зависимостей

  1. Установите необходимые библиотеки:
    npm install lucide-react d3 react-dom

Шаг 4: Замена исходного кода

  1. Откройте папку проекта в проводнике:
    explorer .
  2. Перейдите в папку src
  3. Создайте новый файл PhilosophyGraph.js
  4. Откройте этот файл в текстовом редакторе и вставьте весь код из предоставленного файла
  5. Откройте файл src/App.js и замените его содержимое на:
import React from 'react';
import './App.css';
import PhilosophyGraph from './PhilosophyGraph';

function App() {
  return (
    <div className="App" style={{ height: '100vh' }}>
      <PhilosophyGraph />
    </div>
  );
}

export default App;

Шаг 5: Запуск приложения

  1. Вернитесь в командную строку (она должна быть открыта в каталоге проекта)
  2. Запустите сервер разработки:
    npm start
  3. Автоматически откроется браузер с приложением по адресу: http://localhost:3000
  4. Если браузер не открылся автоматически, откройте его вручную и перейдите по указанному адресу

Шаг 6: Использование редактора философских концепций

В приложении вы можете:

  • Добавлять узлы, представляющие философские категории
  • Создавать связи между узлами с разными типами отношений
  • Перемещать узлы по холсту
  • Масштабировать и панорамировать граф
  • Сохранять и загружать созданные концепции
  • Экспортировать и импортировать концепции в формате JSON
  • Использовать готовые примеры философских систем (Гегель, Кант, Хайдеггер)

Шаг 7: Создание оптимизированной сборки для развертывания

Когда вы готовы разместить приложение на сервере или поделиться им:

  1. Остановите сервер разработки (нажмите Ctrl+C в командной строке)
  2. Создайте оптимизированную сборку:
    npm run build
  3. По завершении в каталоге build будут созданы статические файлы, готовые к развертыванию

Шаг 8: Публикация (опционально)

  1. Содержимое каталога build можно разместить на любом веб-сервере:
    • Загрузить на хостинг через FTP
    • Развернуть на локальном веб-сервере (Apache, Nginx)
    • Использовать сервисы бесплатного хостинга (GitHub Pages, Netlify)

Устранение возможных проблем

  1. Ошибка "command not found" для npm или npx:

    • Убедитесь, что Node.js установлен правильно
    • Перезапустите командную строку
    • При необходимости добавьте путь к Node.js в переменную PATH

  2. Проблемы с запуском на Windows 7:

    • Используйте совместимую версию Node.js (13.x или ниже)
    • Обновите Internet Explorer до последней доступной версии

  3. Ошибки при установке зависимостей:

    • Попробуйте запустить командную строку от имени администратора
    • Проверьте подключение к интернету
    • Используйте команду npm cache clean --force и повторите установку

  4. Приложение не запускается:

    • Проверьте наличие ошибок в консоли браузера (F12)
    • Убедитесь, что порт 3000 не занят другим приложением
