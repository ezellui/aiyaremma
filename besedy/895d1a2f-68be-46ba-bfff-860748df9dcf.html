Из архитектурного описания я вижу, что Claude Service отвечает за:

  • Взаимодействие с Claude API
  • Форматирование запросов и обработка ответов
  • Очередизация и приоритизация запросов
  • Обеспечение асинхронных операций для тяжелых запросов

Из описания архитектуры также видно, что Claude Service использует:

  • PostgreSQL для хранения истории взаимодействий и метаданных
  • MongoDB для хранения результатов анализа
  • RabbitMQ для очередизации запросов

Мне нужно разработать файлы с учётом интеграции с другими сервисами и использования shared библиотек из Фазы 1.
