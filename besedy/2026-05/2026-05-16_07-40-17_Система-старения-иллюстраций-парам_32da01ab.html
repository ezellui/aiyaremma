Архитектура

Три фильтра (illumination-aged-front / -back / -initial) — это копии одного устройства с разнесёнными seed'ами, чтобы шум на трёх иллюстрациях не выглядел одной шкурой. Применяются через filter="url(#...)" на корневом <svg> (carpet front, carpet back, big-initial в дропкапе).

Внутри каждого фильтра — четыре функциональных блока, склеенные через feMerge:

  1. displaced — дрожание контуров (feDisplacementMap поверх SourceGraphic)
  2. coarseOnInk — крупные тёплые foxing-пятна, обрезанные по альфе краски
  3. fineOnInk — мелкое зерно, тоже только на краске
  4. feMerge собирает три слоя в указанном порядке (coarse под fine)

Ключ архитектуры — feComposite operator="in" после каждого слоя шума. Он маскирует шум по альфе displaced, поэтому пятна и зерно появляются только там, где есть краска, а на прозрачной бумаге между элементами иллюстрации шума нет. Это и отличает «иллюминационное» старение от фонового шума пергамента (тот уже сделан через --p-noise-fine/coarse на странице).

Параметры по блокам

Блок 1. Дрожание контуров (displaced)
Код
<feTurbulence type="turbulence" baseFrequency="0.230" numOctaves="3" seed="..."/>
<feDisplacementMap scale="0.85" .../>
  • scale="0.85" — амплитуда искривления в пикселях SVG-юзер-координат. Это главный регулятор «руки писца»: 0.3–0.5 даёт еле заметную вибрацию, 0.85 — текущая «слегка дрожащая», 1.5–2.5 — заметный wobble, >3 контуры начинают визуально ломаться.
  • baseFrequency="0.230" — пространственный период волны искривления. Ниже (0.05–0.1) — крупные плавные «волны» по всему контуру (как если перо вело дрожащая рука); выше (0.5–1.0) — частая мелкая вибрация (как если перо тряслось на коротком отрезке).
  • numOctaves="3" — слойность шума. Больше октав → более «живая» неравномерность дрожания, но дороже по производительности.
  • type="turbulence" — здесь сознательно не fractalNoise. В комментарии diff'а отмечено, что в Firefox 115 ESR fractalNoise на displacement даёт бинарный flicker. Менять только если у тебя нет Firefox-таргета.
Блок 2. Крупные foxing-пятна (coarseOnInk)
Код
<feTurbulence baseFrequency="0.030" numOctaves="3" seed="..."/>
<feColorMatrix values="0 0 0 0  0.080
                       0 0 0 0  0.040
                       0 0 0 0  0.000
                       0 0 0 0.500 -0.070"/>

Это самые «выразительные» пятна — те самые рыжеватые foxing-кляксы на старых иллюстрациях.

  • baseFrequency="0.030" — размер пятен. Чем ниже, тем крупнее: 0.015 даст «лужи», 0.030 — текущие «кляксы», 0.06 — россыпь более мелких. Это твой главный регулятор масштаба пятен.
  • Цветовая матрица (последний столбец — константа, прибавляется к каналу):
    • R: +0.080, G: +0.040, B: +0.000 — тёплый рыже-охристый тинт. Хочешь холоднее/«заплесневеть» — добавь B и убавь R; хочешь насыщенней — пропорционально увеличивай R/G.
    • A-строка 0 0 0 0.500 -0.070 — формула альфы пятна: out_A = 0.500 × source_A − 0.070. Здесь:
      • 0.500 — общая прозрачность пятен. Выше — пятна «жирнее»/виднее.
      • −0.070 — это threshold: вычитает константу из альфы шума, отрезая слабые места. Из-за него пятна выглядят локализованными «островками», а не равномерной грязной поволокой. Сдвиг к −0.15 → пятен меньше, они резче и реже; сдвиг к 0 → пятна сливаются в общий тёплый налёт; положительные значения дадут сплошной слой.
Блок 3. Мелкое зерно (fineOnInk)
Код
<feTurbulence baseFrequency="2.000" numOctaves="2" seed="..."/>
<feColorMatrix values="0 0 0 0  0.060
                       0 0 0 0  0.030
                       0 0 0 0  0.000
                       0 0 0 0.460 0.000"/>

Микрозернистость, имитирующая шероховатость пигмента/износ красочного слоя.

  • baseFrequency="2.000" — высокая частота = очень мелкое зерно. Поднимай для ещё более «пыльного» эффекта (3.0–4.0), опускай (0.5–1.0) для перехода к «среднему» зерну.
  • numOctaves="2" — намеренно меньше, чем у coarse: для мелкого зерна октавы дают избыточный шум и удорожают рендер. Больше 3 — нет смысла.
  • R: +0.060, G: +0.030 — тот же тёплый тон, но слабее: зерно подмешивается к основной краске, не должно перебивать тинт пятен.
  • A: 0.460 × source_A + 0.000 — заметь, здесь нет threshold'а. Это сознательно: для мелкого зерна нужно равномерное «распыление» по всей краске, не локализованные пятна. Если зерно кажется грязным — снижай 0.460 (0.25–0.35 даст чище), если слишком стерильно — поднимай (до 0.6 безопасно).
Блок 4. Финальный feMerge

Порядок узлов важен:

  1. displaced — это и есть «бумага с краской», уже после дрожания контуров.
  2. coarseOnInk сверху — крупные пятна перекрывают часть исходной краски.
  3. fineOnInk ещё сверху — мелкое зерно идёт самым верхним слоем.

Если поменяешь порядок (например, fine под coarse), мелкое зерно начнёт «просвечивать» сквозь пятна — это станет заметно при большой альфе coarse.

Общие настройки фильтра

  • x="-3%" y="-3%" width="106%" height="106%" — расширение области фильтра на 3% во все стороны. Нужно, чтобы feDisplacementMap со scale="0.85" не обрезал контуры на самом краю SVG. Если поднимешь scale сильно выше (например, до 3), увеличивай и этот padding (до 8–10%), иначе крайние линии начнут обрезаться.
  • color-interpolation-filters="auto" — Firefox-safe пометка. В linearRGB-режиме Firefox 115 ESR искажает тёплые тинты (R/G-сдвиги в матрицах). Не убирай.
