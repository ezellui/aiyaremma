Claude2025-04-26 07:33:43#4
размышление

Пользователь прав, что текущая реализация не поддерживает множественность значений для традиций/концепций и философов. В предложенной мной корректировке я добавил простые поля VARCHAR для хранения одного значения, но если категория или связь принадлежит нескольким традициям или связана с несколькими философами, это не будет работать правильно.

Есть несколько способов реализовать поддержку множественности:

  1. Использовать JSONB массивы в PostgreSQL для хранения нескольких значений
  2. Создать отдельные таблицы для связи many-to-many между категориями/связями и традициями/философами

Давайте рассмотрим оба варианта:

Вариант 1 (JSONB arrays) - проще в реализации, но менее нормализован:

  • tradition_concepts JSONB DEFAULT '[]'::jsonb
  • philosophers JSONB DEFAULT '[]'::jsonb

Вариант 2 (дополнительные таблицы) - более нормализованный подход:

  • Таблица traditions/philosophers
  • Таблица category_traditions, category_philosophers
  • Таблица connection_traditions, connection_philosophers

Я думаю, что более правильным будет предложить вариант с JSONB, так как:

  1. Это проще в реализации
  2. Не требует значительных изменений в архитектуре
  3. PostgreSQL хорошо работает с JSONB
  4. Можно легко выполнять поиск по JSONB массивам

Давайте переделаем мои предложения с учетом множественности значений.

Вы правы, текущая реализация не поддерживает множественность значений. Категория или связь может принадлежать нескольким традициям и быть связана с несколькими философами. Предлагаю откорректировать решение для поддержки множественности значений, используя JSONB массивы в PostgreSQL:

В методе preparePrompt класса ClaudeService добавить обработку массивов:

Код · typescript
private async preparePrompt(templateName: string, data: Record<string, any>): Promise<string> {
  try {
    const template = await this.promptService.getTemplate(templateName);
    if (!template) {
      throw new Error(`Template not found: ${templateName}`);
    }
    
    let prompt = template.template;
    
    // Замена параметров в шаблоне
    for (const param of template.parameters) {
      const value = data[param];
      
      if (value === undefined) {
        logger.warn(`Parameter ${param} is missing in data for template ${templateName}`);
        prompt = prompt.replace(new RegExp(`\\{\\{${param}\\}\\}`, 'g'), '');
        continue;
      }
      
      // Обработка массивов
      if (Array.isArray(value)) {
        // Заменяем блоки {{#each param}} ... {{/each}}
        const eachRegex = new RegExp(`\\{\\{#each ${param}\\}\\}([\\s\\S]*?)\\{\\{/each\\}\\}`, 'g');
        prompt = prompt.replace(eachRegex, (match, content) => {
          return value.map((item, index) => {
            return content
              .replace(/\{\{this\}\}/g, item)
              .replace(/\{\{@last\}\}/g, String(index === value.length - 1))
              .replace(/\{\{#unless @last\}\}([^]*?)\{\{\/unless\}\}/g, (m, c) => 
                index !== value.length - 1 ? c : ''
              );
          }).join('');
        });
        
        // Заменяем простые {{param}} на строку с разделителями
        prompt = prompt.replace(new RegExp(`\\{\\{${param}\\}\\}`, 'g'), value.join(', '));
      } else {
        // Обработка обычных значений
        let stringValue = value;
        if (typeof value === 'object') {
          stringValue = JSON.stringify(value, null, 2);
        }
        prompt = prompt.replace(new RegExp(`\\{\\{${param}\\}\\}`, 'g'), stringValue);
      }
      
      // Обработка условных блоков {{#if param}} ... {{/if}}
      const ifRegex = new RegExp(`\\{\\{#if ${param}\\}\\}([\\s\\S]*?)\\{\\{/if\\}\\}`, 'g');
      prompt = prompt.replace(ifRegex, (match, content) => {
        if (Array.isArray(value) ? value.length > 0 : Boolean(value)) {
          return content;
        }
        return '';
      });
    }
    
    return prompt;
  } catch (error) {
    logger.error(`Error preparing prompt: ${error}`);
    throw new Error(`Failed to prepare prompt: ${error}`);
  }
}

Эти изменения позволят корректно обрабатывать массивы tradition_concepts и philosophers в шаблонах промптов.
