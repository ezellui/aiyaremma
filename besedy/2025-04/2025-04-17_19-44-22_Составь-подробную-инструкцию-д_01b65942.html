Инструкция по развертыванию философского веб-приложения на Ubuntu

Вижу, что вы хотите развернуть React-приложение для создания философских концепций. Давайте создадим пошаговую инструкцию для настройки и запуска этого проекта на Ubuntu.

Подготовка системы

  1. Обновление пакетов Ubuntu

    Код · bash
    sudo apt update
sudo apt upgrade -y

  2. Установка необходимых зависимостей

    Код · bash
    sudo apt install -y curl git build-essential

  3. Установка Node.js и npm

    Код · bash
    curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

  4. Проверка установки Node.js и npm

    Код · bash
    node -v
npm -v

Создание проекта React

  1. Создание нового проекта React

    Код · bash
    npx create-react-app philosophy-graph-app
cd philosophy-graph-app

  2. Установка необходимых библиотек

    Код · bash
    npm install lucide-react react-dom react

Подготовка структуры проекта

  1. Создание структуры файлов

    Код · bash
    mkdir -p src/components

  2. Создание компонента PhilosophyGraph

    Код · bash
    touch src/components/PhilosophyGraph.js

  3. Вставка кода в компонент Откройте файл src/components/PhilosophyGraph.js в любом текстовом редакторе (например, nano или vim) и вставьте код из предоставленного файла.

    Код · bash
    nano src/components/PhilosophyGraph.js

    Скопируйте и вставьте код из предоставленного вами файла.

  4. Обновление файла App.js

    Код · bash
    nano src/App.js

    Замените содержимое на:

    Код · jsx
    import React from 'react';
import './App.css';
import PhilosophyGraph from './components/PhilosophyGraph';

function App() {
  return (
    <div className="App" style={{ width: '100vw', height: '100vh' }}>
      <PhilosophyGraph />
    </div>
  );
}

export default App;

  5. Обновление файла index.css

    Код · bash
    nano src/index.css

    Добавьте базовые стили:

    Код · css
    body {
  margin: 0;
  padding: 0;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto', 'Oxygen',
    'Ubuntu', 'Cantarell', 'Fira Sans', 'Droid Sans', 'Helvetica Neue',
    sans-serif;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  overflow: hidden;
}

html, body, #root {
  height: 100%;
  width: 100%;
}

Настройка Tailwind CSS

Так как проект использует классы Tailwind CSS:

  1. Установка Tailwind CSS и его зависимостей

    Код · bash
    npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

  2. Настройка конфигурации Tailwind

    Код · bash
    nano tailwind.config.js

    Обновите содержимое:

    Код · bash
    nano src/index.css

    Добавьте директивы Tailwind вверху файла:

    Код · css
    @tailwind base;

Поскольку в коде используются иконки из библиотеки lucide-react, дополните импорты:

Запуск проекта в режиме разработки

  1. Запуск приложения
    Код · bash
    npm start

Приложение будет доступно по адресу http://localhost:3000

Развертывание для продакшена

Для развертывания приложения в продакшен-среде:

  1. Создание оптимизированной сборки

    Код · bash
    npm run build

  2. Установка веб-сервера (например, nginx)

    Код · bash
    sudo apt install -y nginx

  3. Настройка nginx

    Код · bash
    sudo nano /etc/nginx/sites-available/philosophy-app

    Добавьте конфигурацию:

    Код · nginx
    server {
    listen 80;
    server_name your-domain.com;  # Замените на ваш домен или IP-адрес

    root /path/to/philosophy-graph-app/build;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

  4. Активация сайта и перезапуск nginx

    Код · bash
    sudo ln -s /etc/nginx/sites-available/philosophy-app /etc/nginx/sites-enabled/
sudo nginx -t
