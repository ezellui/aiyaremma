    const outgoing = _outgoingLinks.get(conceptId) || [];

    critiquesOfInfluential,
    syntheses,
    developments,
    rootedness
    };

Алгоритм оценивает революционность философской концепции через несколько ключевых параметров. Он анализирует противопоставления, критику влиятельных идей, синтезы и развития, учитывая исторический контекст и взаимосвязи между философскими концепциями. Алгоритм революционности философской концепции требует глубокого методологического анализа. Ключевые параметры - противопоставление существующим теориям, критическая оценка влиятельных подходов и создание синтетических конструкций. Важно критически оценить весовые коэффициенты и логику взаимосвязи между различными факторами философской новизны.

Алгоритм демонстрирует интересную попытку формализации, но имеет ряд серьезных философско-исторических проблем:

Обоснованные элементы

1. Противопоставление как маркер новизны (oppositionsToEarlier * 2)

  • Разумно: революционные концепции действительно часто противопоставляют себя предшествующей традиции (Декарт vs схоластика, Ницше vs христианская метафизика)

2. Критика влиятельных концепций (critiquesOfInfluential * 1.5)

  • Логично: атака на доминирующие парадигмы - признак радикальности (Маркс критикует Гегеля, Деррида - западную метафизику)

3. Синтез как креативность (syntheses * 2)

  • Спорно, но интересно: синтез может быть революционным (Кант), но может быть и консервативным эклектизмом

Проблемные аспекты

1. Противоречивость формулы "укорененности"

const rootedness = influences / Math.max(oppositionsToEarlier, 1);
total = ... - rootedness * 3

Проблема: Концепция с нулевыми противопоставлениями получает максимальную укорененность (∞) и бесконечно отрицательный индекс. Но это может быть:

  • Парадигмальная новация, которой нечему противопоставляться (досократики, Платон)
  • Радикальный разрыв вне оппозиции (Витгенштейн начинает новую игру, а не спорит со старой)

2. Линейность времени vs циркулярность влияний Алгоритм учитывает только sourcePhil.birth < philosopher.birth, игнорируя:

  • Посмертное влияние (Спиноза революционен для XVIII-XIX вв., но современники его не читали)
  • Ретроактивные переоткрытия (стоики для Фуко, Аристотель для Хайдеггера)

3. developments как входящий параметр - искажение

const developments = incoming.filter(r => r.type === 'develop').length;

Это считает, сколько раз концепцию развивали потомки, что:

  • Зависит от будущего (non-contemporary bias)
  • Смешивает революционность с влиятельностью
  • Делает революционность функцией времени создания графа

Пример: концепция 2024 года не может иметь developments, даже если она абсолютно революционна.

4. Отсутствие контекстуальных факторов

Алгоритм игнорирует:

  • Эпистемологические разрывы (Кун): революция - это смена парадигмы, а не просто оппозиция
  • Институциональный контекст: концепция может быть радикальной в одном поле и банальной в другом
  • Retroductive reasoning: некоторые концепции революционны не оппозицией, а открытием нового пространства вопросов (Фреге для аналитической философии)

5. Типологическая примитивность

Бинарная категория type === 'oppose' не различает:

  • Диалектическое отрицание (Aufhebung у Гегеля)
  • Радикальное отвержение (Ницше к Сократу)
  • Уточняющую критику (Рассел к Фреге)
  • Деконструктивное смещение (Деррида)

Философские альтернативы

Более обоснованный подход мог бы включать:

  1. Коэффициент парадигмального сдвига: не просто оппозиции, но изменение базовых вопросов/методов

  2. Темпоральная асимметрия: 

    const futureImpact = outgoing.filter(later_than_X_years).length;
const contemporaryOpposition = incoming.filter(same_generation).length;

  3. Концептуальная плодотворность: не количество developments, а разнообразие интерпретаций

  4. Индекс "непереводимости": концепции, требующие новых терминов (différance, Dasein, simulacre)

Вывод

Алгоритм методологически наивен с точки зрения истории философии, хотя и схватывает некоторые интуиции. Главная проблема - редукция революционности к сетевым метрикам, игнорирующая качественные скачки в концептуальном пространстве.

Революционность - это не функция графа связей, а событие смещения проблемного поля (по Фуко/Делёзу), которое такая формализация по определению не может уловить.

/**
 * Универсальная функция для генерации результатов метрик
 * @param {Array} data - массив данных результатов
 * @param {string} title - заголовок метрики
 * @param {string} description - описание метрики
 * @param {string} metricKey - ключ метрики для descriptions

 * @param {boolean} isDecimal - форматировать ли как десятичное
 * @param {Object} options - дополнительные опции
 * @param {boolean} options.isComposite - составная ли метрика (с подхарактеристиками)

 * @param {Function} options.getConceptDescription - функция для получения описания концепции
 */
function generateMetricResults(data, title, description, metricKey, valueKey, isDecimal, options = {}) {
    const {
        isComposite = false,
        getDetailsHTML = null,
        getConceptDescription = (item) => item.node.description || null
    } = options;
    
    if (!data || data.length === 0) {
        return `
            <div class="stats-content-header">
                <h3 class="stats-content-title">${title}</h3>
                <p class="stats-content-subtitle">${description}</p>
                
                <div class="stats-content-actions">
                    <button class="stats-action-btn secondary" 
                            id="visualize-btn-${metricKey}"
                            onclick="toggleMetricVisualization('${metricKey}')">
                        <span id="visualize-icon-${metricKey}">📏</span>
                        <span id="visualize-text-${metricKey}">Визуализировать размером</span>
                    </button>
                </div>
            </div>
            
            ${generateMetricDescriptionBlock(metricKey)}
            
            <div class="empty-state">
                <div class="empty-state-icon">📊</div>
                <div class="empty-state-text">Нет данных для отображения</div>
            </div>
        `;
    }
    
    return `
        <div class="stats-content-header">
            <h3 class="stats-content-title">${title}</h3>
            <p class="stats-content-subtitle">${description}</p>
            
            <div class="stats-content-actions">
                <button class="stats-action-btn secondary" 
                        id="visualize-btn-${metricKey}"
                        onclick="toggleMetricVisualization('${metricKey}')">
                    <span id="visualize-icon-${metricKey}">📏</span>
                    <span id="visualize-text-${metricKey}">Визуализировать размером</span>
                </button>
            </div>
        </div>
        
        ${generateMetricDescriptionBlock(metricKey)}
        
        <div class="metric-results-grid">
            ${data.map((item, index) => {
                const value = item[valueKey];
                const displayValue = isDecimal ? value.toFixed(4) : Math.round(value);
                const conceptDesc = getConceptDescription(item);
                const hasDetails = isComposite || conceptDesc;
                
                // Генерируем HTML для деталей
                let detailsHTML = '';
                if (hasDetails) {
                    if (isComposite && getDetailsHTML) {
                        // Составная метрика - показываем подхарактеристики + описание
                        detailsHTML = getDetailsHTML(item, index);
                    } else if (conceptDesc) {
                        // Простая метрика - только описание концепции
                        detailsHTML = `
                            <div class="metric-detail-panel simple-detail">
                                <div class="metric-concept-description">
                                    <strong>О концепции:</strong>
                                    <p>${conceptDesc}</p>
                                </div>
                            </div>
                        `;
                    }
                }
                
                return `
                    <div class="metric-result-card ${hasDetails ? 'has-details' : ''}" 
                         data-concept-id="${item.node.id}"
                         onclick="highlightNodeById('${item.node.id}')">
                        <div class="metric-result-rank">#${index + 1}</div>
                        <div class="metric-result-name">${item.node.label}</div>
                        <div class="metric-result-value">${displayValue}</div>
                        <div class="metric-result-philosopher">${item.node.concept}</div>
                        
                        ${hasDetails ? `
                            <button class="metric-expand-btn" 
                                    onclick="event.stopPropagation(); toggleMetricDetails(this);"
                                    title="Показать детали">
                                <span class="expand-icon">▼</span>
                            </button>
                        ` : ''}
                        
                        ${hasDetails ? detailsHTML : ''}
                    </div>
                `;
            }).join('')}
        </div>
    `;
}

function toggleMetricDetails(button) {
    const card = button.closest('.metric-result-card');
    const panel = card.querySelector('.metric-detail-panel');
    const icon = button.querySelector('.expand-icon');
    
    if (!panel) return;
    
    const isExpanded = card.classList.contains('expanded');
    
    if (isExpanded) {
        // Сворачиваем
        panel.style.display = 'none';
        icon.textContent = '▼';
        card.classList.remove('expanded');
    } else {
        // Разворачиваем
        panel.style.display = 'block';
        icon.textContent = '▲';
        card.classList.add('expanded');
    }
}

Философские примеры критической силы

Высокая критическая сила без революционности:

  • Секст Эмпирик (скептицизм) - разрушает все догмы, но ничего не строит
  • Карнап (критика метафизики) - показывает бессмысленность, но не создаёт альтернативы
  • Ранний Витгенштейн - "о чём нельзя говорить, о том следует молчать"

Низкая критическая сила при высокой революционности:

  • Спиноза - создаёт новую онтологию, но мало критикует предшественников напрямую
  • Гуссерль - открывает феноменологию, но больше строит, чем разрушает

Проблемы исходного алгоритма

1. Измеряет активность, а не эффективность

raw: critiques.length + oppositions.length

Проблема: количество ≠ сила.

Пример абсурда:

  • Философ A написал 100 мелких критических заметок → высокий индекс
  • Философ B написал одну работу, разрушившую целую парадигму (Рассел → Фреге) → низкий индекс

2. targetInfluence как прокси качества - философски спорно

targetInfluence: targetInfluence / (critiques.length + oppositions.length || 1)

Идея: критика влиятельной концепции = сильная критика.

Контрпримеры:

  • Банальная критика Платона (тысячи схоластов) - высокая targetInfluence, нулевая сила
  • Парадокс Рассела (Фреге мало кто знал в 1902) - низкая targetInfluence, ОГРОМНАЯ сила
  • Критика неизвестной, но гениальной концепции - низкая targetInfluence, высокая философская ценность

3. Нет учёта последствий критики

Сильная критика должна что-то породить:

  • Развития (develop)
  • Синтезы (synthesize)
  • Новые концепции (emerge_from)

Исходный алгоритм это игнорирует.

4. Не различает типы критики

  • Деструктивная (Ницше → христианская мораль) - разрушение без альтернативы
  • Конструктивная (Кант → рационализм) - критика как основа нового
  • Имманентная (Гегель → Кант) - критика изнутри, развитие
  • Внешняя (позитивисты → метафизика) - отвержение как псевдопроблемы

Все получают одинаковый вес.

    const oppositions = outgoing.filter(r => r.type === 'oppose');

    const weightedCriticalActivity = outgoing.reduce((sum, r) => {
        const typeWeight = {
            'critique': 2,
            'oppose': 3

        return sum + typeWeight * (r.weight || 1);
    }, 0);

        if (targetInfluence > 15) acc.majorTargets++; // Центральные концепции

        effectiveness * 2.0 +                    // Эффективность (главное!)
        targetedPhilosophers * 0.8 +             // Широта атаки
        eraSpan / 100 +                          // Временной диапазон
        (constructivenessRatio > 0.3 ? 3 : 0);   // Бонус за конструктивность
    
    return {
        total,
        
        // Активность
        rawCriticalActivity,
        weightedCriticalActivity,
        
        // Качество целей
        targets: {
            majorTargets: targetAnalysis.majorTargets,
            mediumTargets: targetAnalysis.mediumTargets,
            minorTargets: targetAnalysis.minorTargets,
            averageInfluence: averageTargetInfluence
        },
        
        // Эффективность
        effectiveness,
        criticalConsequences,
        ownDevelopments,
        
        // Широта
        targetedPhilosophers,
        eraSpan,
        
        // Тип критики
        constructivenessRatio,
        retroactiveCritiques,
        contemporaryCritiques,
        
        // Для обратной совместимости
        raw: rawCriticalActivity,
        weighted: weightedCriticalActivity,
        targetInfluence: averageTargetInfluence
    };
}

Сила критики измеряется последствиями, а не количеством. Одна разрушительная критика (Юм → причинность) важнее ста поверхностных.

2. Категоризация целей

majorTargets, mediumTargets, minorTargets

Различает критику Платона (major) от критики забытого схоласта (minor). Философски честнее, чем простое среднее.

3. Конструктивность

constructivenessRatio

  • Кант - критикует, чтобы построить (высокий ratio)
  • Ницше - критикует, чтобы разрушить (низкий ratio)

Оба типа ценны, но по-разному.

4. Временная перспектива

retroactiveCritiques vs contemporaryCritiques
  • Критика прошлого - пересмотр традиции (историчность)
  • Критика современников - полемика (актуальность)

5. Широта атаки

targetedPhilosophers, eraSpan

Системная критика (Деррида → вся метафизика) сильнее точечной (критика одного тезиса).
