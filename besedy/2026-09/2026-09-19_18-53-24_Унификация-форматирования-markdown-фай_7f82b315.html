The session covered six interconnected tasks: converting an edited Word document (.docx) to Markdown with preserved bold/italic formatting; generating a diff between original and edited Markdown files; building an edited HTML from the Markdown using a reconstructed converter script (md2html.py); generating a print PDF (Vo_vremena_velikanov_kniga_ed.pdf) via a Playwright-based Paged.js pipeline (html_to_book_pdf.py); diagnosing a two-page increase versus the original PDF; and preparing files for a hardcover binding.

Claude reconstructed the original md2html.py converter by reverse-engineering the existing HTML, achieving byte-identical reproduction of the original file before applying it to the edited version. Key fixes across the pipeline included: adding JetBrains Mono italic and bold 700 weight variants (both in Google Fonts links and embedded PDF fonts) to support emphasis in the manuscript insert sections; adding a "Повесть" genre subtitle to the title page; and fixing a white hairline at the right page edge by trimming the PDF MediaBox to the actual painted area (491×756 CSS pixels). A first-publication credit line ("Впервые опубликовано в журнале «Волга», 2026, № 9–10.") was added to the colophon page between the author/title line and the production credits, with typographically correct punctuation (guillemets, en-dash range, non-breaking space after №).

Как устроен исходный конвертер (восстановлено)

  • Шапка, стили, навигация, <head> и скрипт Луны берутся из исходного HTML как из шаблона. Заголовки глав тоже берутся оттуда, по порядку.

  • Если абзац начинается с тире или дефиса, он получает класс dialogue с ржавой чертой слева.
  • Первый абзац главы получает класс lede и буквицу. Если глава начинается с реплики, буквицей становится тире.
  • Класс manuscript получает сплошной блок из 10 абзацев, от «Надин Шетти, 1986.» до «Я смотрю на провалы». Скорее всего, в исходном скрипте было такое же ручное правило. Я привязал его к тем же двум якорям, и в правке блок остался таким же.
  • Инлайн-разметка md обрабатывается CommonMark-парсером: *…* становится <em>, **…** — <strong>, \* — буквальной звёздочкой.

"""Растровая оснастка для спуска полос: вылеты, подложка под шов, заливка корешка.

Лечит дефект исходника: на всех 120 полосах фон не доходит до ПРАВОГО обреза
примерно на 0,25 мм — там незакрашенная полоска, дающая белую волосяную линию.
"""
import io
import numpy as np
import pypdfium2 as pdfium
from PIL import Image

DPI = 300
PX_MM = DPI / 25.4


def jpeg(arr, q=92):
    buf = io.BytesIO()
    Image.fromarray(np.ascontiguousarray(arr)).save(buf, 'JPEG', quality=q, optimize=True)
    return buf.getvalue(), arr.shape[1], arr.shape[0]


def _extend(strip, width):
    """Продолжить полосу наружу зеркальной укладкой.
    У strip последний столбец примыкает к границе; результат идёт от границы
    наружу. Укладка, а не растяжение: масштаб зерна и звёзды не размазываются."""
    blocks, cur, got = [], strip[:, ::-1], 0
    while got < width:
        blocks.append(cur)
        got += cur.shape[1]
        cur = cur[:, ::-1]
    return np.concatenate(blocks, axis=1)[:, :width]


class Edges:
    def __init__(self, path, dpi=DPI):
        self.doc = pdfium.PdfDocument(path)
        self.dpi = dpi
        self.px_mm = dpi / 25.4
        self._cache = {}
        self.sliver_px = None

    def arr(self, pageno):
        """Растр полосы с залеченной правой кромкой."""
        if pageno in self._cache:
            return self._cache[pageno]
        if len(self._cache) >= 12:        # 300 dpi × 120 полос — это 1,3 ГБ, не влезет
            self._cache.pop(next(iter(self._cache)))
        im = self.doc[pageno - 1].render(scale=self.dpi / 72.0).to_pil().convert('RGB')
        a = np.asarray(im).copy()
        L = a.mean(axis=2)
        k = 0
        while k < int(2 * self.px_mm) and L[:, -1 - k].mean() > 240:
            k += 1
        if k:
            a[:, -k:] = a[:, -k - 1:-k]           # растянуть последний живой столбец
            self.sliver_px = max(self.sliver_px or 0, k)
        self._cache[pageno] = a
        return a

    def bleed(self, pageno, bleed_mm):
        a = self.arr(pageno)
        b = max(2, int(round(bleed_mm * self.px_mm)))
        pad = np.pad(a, ((b, b), (b, b), (0, 0)), mode='reflect')
        H, W = pad.shape[:2]
        return {'top': pad[0:b, :, :], 'bottom': pad[H - b:H, :, :],
                'left': pad[b:H - b, 0:b, :], 'right': pad[b:H - b, W - b:W, :]}

    def underlay_right(self, pageno, w_mm=1.2):
        """Тёмная подложка под незакрашенную кромку у правого обреза."""
        a = self.arr(pageno)
        w = max(2, int(round(w_mm * self.px_mm)))
        return a[:, -w:, :]

    def spine_fill(self, left_page, right_page, width_mm, sample_mm=2.0):
        """Заливка корешка. Берём только крайние 2 мм — дальше на полосе
        начинается рельс с кружками глав, его зеркало в корешке недопустимо."""
        w = max(4, int(round(width_mm * self.px_mm)))
        s = max(2, int(round(sample_mm * self.px_mm)))
        al, ar = self.arr(left_page), self.arr(right_page)
        h = min(al.shape[0], ar.shape[0])
        L = _extend(al[:h, -s:, :], w).astype(np.float32)
        R = _extend(ar[:h, :s, :][:, ::-1, :], w)[:, ::-1, :].astype(np.float32)
        t = np.linspace(0, 1, w, dtype=np.float32)[None, :, None]
        return (L * (1 - t) + R * t).astype(np.uint8)
