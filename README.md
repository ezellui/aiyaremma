Распакуйте ZIP целиком и откройте index.html в современном браузере. Сайт работает с диска без сервера и интернета.

Поиск охватывает названия, темы и текст реплик. На странице беседы выберите ветку, откройте нужный файл и скачайте выбранную версию.

На вкладке изменений показано сравнение с ближайшей предыдущей версией этого файла по той же линии разговора. Для очень крупных изменений доступно скачивание версий.

Снимки из выгрузки сохраняют файлы, перечисленные в исходном ZIP. Восстановление истории по JSON охватывает доступные операции создания и изменения текстовых файлов.

HTML, SVG и код вложений показываются как исходный текст. Для просмотра скачанного HTML как страницы откройте его отдельно.

Раздел «Память» содержит общую сводку и 103 отдельных заметки. Поиск по памяти охватывает полный текст. Оригиналы доступны для скачивания в Markdown. Ссылки на беседы следуют тематическому указателю по упоминаниям.
