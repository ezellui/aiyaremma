Распакуйте ZIP целиком. В Windows запустите start.cmd, на других системах — python start.py. Скрипт сам откроет архив в браузере. Сервер слушает только 127.0.0.1, интернет не нужен.
Вручную из распакованной папки: python -m http.server 3000 --bind 127.0.0.1. Затем откройте http://127.0.0.1:3000/.
Предпросмотр читает исходные файлы из faily/ по запросу. HTML и SVG показаны как исходный текст.
Поиск охватывает названия, темы и текст реплик. На странице беседы выберите ветку вверху или переключите её кнопками у реплики, откройте нужный файл и скачайте выбранную версию.
На вкладке изменений показано сравнение с ближайшей предыдущей версией этого файла по той же линии разговора. Для очень крупных изменений доступно скачивание версий.
Снимки из выгрузки сохраняют файлы, перечисленные в исходном ZIP. Восстановление истории по JSON охватывает доступные операции создания и изменения текстовых файлов.
HTML, SVG и код вложений показываются как исходный текст. Для просмотра скачанного HTML как страницы откройте его отдельно.
Раздел «Память» содержит общую сводку и отдельные заметки. Поиск по памяти охватывает полный текст. Оригиналы доступны для скачивания в Markdown. Ссылки на беседы следуют тематическому указателю по упоминаниям.
