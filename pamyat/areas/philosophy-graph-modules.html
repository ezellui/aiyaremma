МИНЫ ДЕЛЕГИРОВАНИЯ

  • event.currentTarget: часть кода берёт элемент не из довода, а из НЕЯВНОГО ГЛОБАЛЬНОГО event (const header = event.currentTarget в toggleSection). При встроенном обработчике это сама кнопка, при делегировании — document. Лечение общее: на время действия window.event подменяется прослойкой (Proxy) с нужным currentTarget; в finally свойство удаляется, возвращая доступ через прототип
  • Имя действия нельзя выводить из одного текста обработчика: у поля поиска легенды один код висит и на oninput, и на onfocus. Ключ — ПАРА «событие + код»
  • Шесть ошибок преобразования, видных только на настоящем коде: подстановка бывает ЧАСТЬЮ строки ('phil-internal-${id}') → шаблонная строка; приставка пространства имён лезла ВНУТРЬ строковых постоянных (toggleSection('rubrics') → 'DATA.rubrics') — строки на время правки прячутся; разметка бывает в обычных строках с ЭКРАНИРОВАННЫМИ кавычками; повторный ввоз в main.js; один обработчик встречается и в статике, и в генераторах — имя одно, тело в реестр ОДИН раз (поймал сам реестр)
