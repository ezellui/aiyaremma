ПУТИ И ЗАПУСК

Все пути в tools/paths.mjs и paths.py (близнецы). Запуск БЕЗ ДОВОДОВ — умолчания верны. Chrome и puppeteer в окружении ЕСТЬ, ровно по путям из readme §7. ИСКАТЬ надо find / -name chrome, а не через ~ (HOME не /home/claude).

node tools/remap.mjs собрать          # ВОСЕМЬ шагов, стирает дерево само
node tools/check_modules.mjs ; node tools/layers.mjs ввозы ; node tools/boot_values.mjs
python3 tools/bridge_debt.py ; node tools/maps_fresh.mjs ; node tools/map_tree.mjs
python3 tools/make_ref.py ; (setsid bash tools/serve.sh app 8711 &)
BASE=http://127.0.0.1:8711/ node tools/assert_probe.mjs index.html

ПРИБОРЫ ПО ЭТАЛОНАМ: довод run, не «эталон» — node tools/<прибор>.mjs run index.html /tmp/снимки/X.json, затем node tools/baseline.mjs проверить <прибор> X.json. Обход — тремя частями (run index.html m1.json 1|2|3), потом merge, потом проверить. ЧАСТЬ ОБХОДА ~4–5 МИНУТ: запускать (setsid … > /tmp/log 2>&1 &) и ждать sleep 260. serve.py намертво занимает сокет; пересоздание app/ под работающим сервером его роняет — поднимать на НОВОМ порту. assert_probe рассчитан на СБОРКУ, на _ref-* он не идёт; для одностраничной стороны — compare/probe6/7/8/css_probe.
