## ДЕФЕКТ БЕЗРАЗРЫВНОГО РЕЖИМА — И МОЯ СОБСТВЕННАЯ ОШИБКА ЗАМЕРА
- МОЙ ПЕРВЫЙ ВЫВОД «в seamless теряется 43% описаний» БЫЛ НЕВЕРЕН. Прибор
  выставлял `chronologyModeSelect.value` БЕЗ события change, а глобальную
  переменную режима держит в согласии со списком именно обработчик change.
  То есть я сам развёл список и переменную, а потом померил последствие.
  ЭТО ТОТ ЖЕ КЛАСС, ЧТО «проверка сверяет то, что сама же и построила».
  ПРАВИЛО: правку формы делать через page.select / dispatchEvent('change'),
  а не присваиванием value
- ЧТО ОСТАЛОСЬ НАСТОЯЩИМ ДЕФЕКТОМ, достижимым БЕЗ приборов: `findAndShowPath`
  восстанавливает `currentChronologyMode` ДО разбора рёбер, а окно описаний и
  подсветка читают ту же живую переменную ещё позже. Достаточно найти путь в
  режиме «без разрывов» и ПЕРЕКЛЮЧИТЬ СПИСОК ОБРАТНО — окно описаний
  открывается ПУСТЫМ (связи пройдены против стрелок и не находятся)
- СВЕРКА ДО/ПОСЛЕ на трёх сценариях (patchwork/check_seamless.mjs, обе версии
  одностраничного исходника):
  1) режим выбран в списке по-человечески — до: связь есть; после: связь есть
  2) список и переменная разошлись — до: НЕТ связи и стрелка врёт «→»;
     после: связь есть, стрелка «←»
  3) режим переключён ПОСЛЕ поиска, потом открыто окно — до: НЕТ связи;
     после: связь есть
- ЛЕЧЕНИЕ (внесено в патч, метка SEAMLESS-PATCH, 5 правок): режим приходит
  ДОВОДОМ `mode` в `resolvePathLinkList` и `highlightPath`; `findAndShowPath`
  передаёт `selectedChronologyMode`; режим кладётся в `currentPathData`;
  окно описаний берёт его оттуда (с откатом на текущий, если записи нет).
  Новых имён верхнего уровня правка НЕ вводит — только местные доводы
- ЗЛАЯ ИРОНИЯ ОСТАЁТСЯ: seamless — самый удачный режим по прочим показателям
  (путей 110 из 120 против 97 у strict, средняя длина 5.23 против 6.32)

## МОЯ ГИПОТЕЗА О ВЕСАХ — ПРОВЕРЕНА И ОПРОВЕРГНУТА
- Ожидал, что `cost = 4 - weight` (shortest-path.js:105), складывающий
  несоизмеримые ранги разных слоёв, потянет пути к типологическим рёбрам
  (у них вес 3 значит «схождение разительное»)
- ЗАМЕР (200 пар): доля типологических среди отрезков пути с весами 6.7%,
  БЕЗ весов 8.6% — веса не притягивают их, а слегка отталкивают. Гипотеза
  неверна
- ЧТО ВЕСА ДЕЛАЮТ НА САМОМ ДЕЛЕ, и делают как задумано: доля веса 3 среди
  отрезков 37% → 50.8%, веса 1 — 5% → 2.3% (в графе 38.5% и 6%)

## ЗАМЕРЫ ПО ПУТЯМ (200 случайных пар, строгий режим, веса и направления вкл.)
- путь есть у 165 из 200; длины 2–10, сгущение на 5–7, средняя 6.36
- **у 133 путей из 165 (81%) есть хотя бы один шаг НАЗАД по времени**
  (207 таких шагов на 884 отрезка = 23%). Приложение об этом ЧЕСТНО ПИШЕТ
  («Ход времени: 1859 → 1833 → 1859 → 1889 · разрывов: 1»)
- межтрадиционных отрезков 436 из 884 (49%)
- типологические: в графе 55 рёбер (3.4%), в путях 6.7% отрезков и
  **в 44 путях из 165 (27%)**. Это не украшение, а несущие мосты: галочка
  «без типологических» отнимает 14 путей из 165 и удлиняет остальные
  (6.36 → 6.66)
- в путях встретились 20 типов связей из 21; не встретился только `apply`
  (он рефлексивный по определению — верно)

## ЧТО ИМЕННО ВЫДАЁТ ПАНЕЛЬ И ОКНО (пригодится при описании)
- панель: цепочка «философ / концепция» со стрелками (→ ← ↔), «Длина пути»,
  «Ход времени» по годам с числом разрывов, название режима, «Традиции:
  различных N, переходов M» и перечень самих переходов
- окно: шапка о традициях, кнопка описаний узлов, на каждый отрезок — тип
  связи словом, вес словом («вес 3 — сильная связь»), строка о традициях
  («Переход между традициями …» / «Продолжение в традиции …» / «Внутри одной
  системы») и текст обоснования; при раскрытии — полные описания узлов
- ОБРАЗЦОВЫЙ СЛУЧАЙ ДЛЯ ПОКАЗА: Метемпсихоз → Анамнесис → Врождённые идеи →
  Синтетические априори → Схематизм → Символические формы → Форма жизни.
  Семь концепций, монотонно по времени 570 до н.э. → 1889, пять переходов
  традиций, последний отрезок типологический и в описании прямо сказано,
  что Кассирер умер в 1945-м, а «Исследования» вышли в 1953-м
- ВТОРОЙ ОБРАЗЕЦ, показывающий цену галочки: Длительность → Форма жизни.
  С типологическими — Бергсон → Дильтей → Гуссерль → Витгенштейн (длительность,
  переживание, жизненный мир, форма жизни). БЕЗ них — Бергсон → Ризома →
  Большой Другой → Форма жизни, та же длина, но время идёт вспять и разрывов 2

## ФЛАЖОК «БЕЗ ВНУТРЕННИХ СВЯЗЕЙ» СДЕЛАН (метка OWNLINKS-PATCH)
- [stated] Решение пользователя: не четвёртая кнопка, а ДОПОЛНИТЕЛЬНАЯ ГАЛОЧКА,
  появляющаяся только в положении «внутри традиций»
- УСТРОЙСТВО: заведено четвёртое ЗНАЧЕНИЕ строки взгляда `within_ext`, а не
  булев признак рядом с ней. Довод: строку взгляда уже умеют все —
  ключ кеша `_generativityCacheByScope`, проверка в `setInfluenceScope`,
  подпись `INFLUENCE_SCOPE_LABELS[influenceScope]` в подробностях. Булев
  признак пришлось бы примешивать в четырёх местах
- НОВЫХ ИМЁН ВЕРХНЕГО УРОВНЯ НЕТ ВОВСЕ: флажок зовёт тот же
  `setInfluenceScope('<литерал>')` тем же атрибутом onclick, что и кнопки,
  ⇒ сборка отобразит его на УЖЕ СУЩЕСТВУЮЩЕЕ действие `set-influence-scope`
  (проверено по app/actions_map.json: код `setInfluenceScope('${k}')`,
  attr onclick, один довод из dataset). Выражения вида
  `setInfluenceScope(this.checked ? … : …)` НЕ ГОДЯТСЯ — целевое значение
  вычисляется в шаблоне при отрисовке, переключатель всё равно
  перерисовывается на `emit('stats-stale')`
- ЧЕТЫРЕ ПРАВКИ: значение в `INFLUENCE_SCOPE_LABELS`; отбор в
  `linkInInfluenceScope` (переписан явно на три случая — прежний тернарник
  `sc === 'within' ? same : !same` на четырёх значениях лгал бы);
  ТОТ ЖЕ отбор в `generativityScores`; вид в `influenceScopeSwitcher`
  (`within_ext` отфильтровано из ряда кнопок, кнопка «внутри традиций»
  активна при обоих значениях) плюс стиль `.influence-scope-own`
- ДВА МЕСТА ОТБОРА ОБЯЗАНЫ БЫТЬ В СОГЛАСИИ: генеративность — первое из трёх
  слагаемых влиятельности. Разойдись правила, метрика считала бы часть по
  одному взгляду, часть по другому, оставаясь ВНУТРЕННЕ СОГЛАСНОЙ и потому
  неотличимой от исправной
- ПРИЁМКА `patchwork/check_ownlinks.mjs` (пять проверок): три прежних
  положения дают РОВНО прежние числа; при флажке итог совпадает с
  НЕЗАВИСИМЫМ внешним расчётом (эталон снят до правки); снятие флажка
  возвращает прежнее; кнопка «внутри традиций» остаётся нажатой; ровно ноль
  у четверых из однолюдных традиций. Всё 0.00e+0, ошибок страницы 0
- ПРОВЕРЕНА НА ПОРЧЕ: снял одну строку отбора ТОЛЬКО в генеративности —
  проверка 2 дала расхождение 1.0e+1 у Сократа, остальные молчали. То есть
  ловится именно рассогласование двух мест
