Замысел механики (принят пользователем как основание переписывания)

  • Качество камней и «хватка» растут по одной кривой; хватка не разжимается (recomputeGrip делает Math.max с прежним значением). Согласие и открытость лишь замедляют рост
  • Настоящая развилка одна — акт VII, Кольцо Судьбы, просьба Йаванны отдать камни. И камней уже нет: Мелькор взял их раньше. Ответ определяет не исход, а кем был Феанор в этот миг
  • Феанор: Пламя / Тайна / Согласие. Камни: Свет / Ясность / Нерушимость (взято из текста, не RPG-набор)
  • Чисел в интерфейсе нет — качественные описания через QUALIA; числа по «D» или ?debug=1

Архитектура каркаса

  • Разделы скрипта пронумерованы 1–10: утилиты, модель, MARKS, QUALIA, КОНТЕНТ, движок, оценка концовок, отрисовка, самопроверка, запуск
  • Сцены — массив SCENES со схемой {id, act, title, text(s)→[абзацы], choices[]}; выбор — {id, text, note?, when?, apply, chronicle, next}; chronicle обязательна
  • Концовки — таблица правил ENDINGS {id, title, priority, test, text, coda}, оценщик берёт наибольший приоритет; есть fallback с -Infinity
  • MARKS — реестр меток, mark() падает на незарегистрированной; заменяет прежние 61 флаг, из которых 36 не читались
  • SELFTEST.run() в консоли: проверка схемы + ПОЛНЫЙ перебор всех траекторий (не Монте-Карло), достижимость каждой концовки, диапазоны. Ловит Math.random в логике, битые next, дубли id
  • Math.random в логике и тексте запрещён и проверяется автоматически
  • Хроника — от третьего лица в прошедшем времени, тогда как сцена обращается на «ты»

Дизайн

  • Палитра из вещества сюжета: --ash #12100e, --iron #1c1916, --rule #2e2a24, --parchment #ded5c4, --smoke #8b8274, --mingled #f2e3cd (смешанный свет — только как свечение, никогда как фон), --laurelin #e0a63c, --telperion #a8bcc6, --ember #7d3126
  • Шрифты: Old Standard TT (заголовки), PT Serif (текст), PT Sans Narrow (хроника, служебное) — все с кириллицей
  • Подпись страницы: виньетка «хватки» — чем крепче держит, тем плотнее мир смыкается вокруг текста. Единственный оркестрованный эффект
  • Три камня рисуются SVG, всё выведено из состояния: свечение — Свет, насыщенность — Ясность, резкость граней — Нерушимость, красная жила — Хватка
  • Выборы — строки с маркером «›», не кнопки-коробки. Эмодзи запрещены
  • Совместимость под тестовое окружение пользователя (Chrome 109, Firefox 115 ESR): без :has(), без color-mix(), без container queries. Хранилище не используется вовсе

Канонические поправки, которые надо удержать при наполнении

  • Слово «силима» обязано звучать
  • Эзеллохар — зелёный холм, а не «священные воды»; росу Древ собирали в колодцы Варды
  • Тулкас без оружия, борется голыми руками
  • Феар в Чертогах Мандоса не блуждают — призрака Мириэль в кузнице быть не может
  • Эльф не может стать Валой; Эру не является лично в Валинор
  • Камни были совершенны и освящены Вардой так, что нечистая плоть обжигалась; катастрофа не в изготовлении, а в любви к изготовленному
  • Феанор — единственный из нолдор, кого Мелькор не совратил; ветки «союз с Мелькором» быть не должно
  • Регистр концовок — элегический, не «и ты стал величайшим»

Оснастка: две поправки, найденные при работе над актом II

  • Учёт меток переведён со статического разбора исходников на замер во время прогона (MARK_WRITES / MARK_READS в mark() и has()). Регулярка по тексту apply не видела чтений через вспомогательную функцию craftYield и ложно объявляла все CRAFT_* непрочитанными. Незарегистрированная метка теперь роняет и has(), не только mark()
  • Формула хватки перекалибрована: сдвиг gripBias входит ВНУТРЬ насыщающей кривой, а не поверх неё. Снаружи он становился главным слагаемым, и 37 % путей упирались в потолок шкалы. Итог: sat(clamp(q + gripBias, 0, 140), 1.60) * 1.14 − (accord*0.45 + (100−secrecy)*0.25) * 0.85, затем Math.max с прежним значением
  • Добавлен SELFTEST.calibrate(key) — печатает квантили итоговых значений и занятость нынешних полос QUALIA. Пороги шкалы хватки поставлены по квантилям полного перебора: [0, 1, 30, 46, 58, 70, 79], занятость 1.6 / 14 / 22.2 / 23.9 / 22.2 / 10.6 / 5.5 %. ПЕРЕСЧИТЫВАТЬ после каждого нового акта
  • Полный перебор теперь вызывает и text(), и chronicle() на каждом узле, чтобы падали и они; копирование состояния переведено с JSON на ручное cloneState (перебор вырос до 363 тыс. траекторий)
  • buildStones(n) принимает число камней и перестраивает SVG; renderStones следит за s.count. Раскладка проверена для n = 1 / 3 / 7, всё в границах поля 300×120

Оснастка: три поправки, найденные при работе над актом III

  • Дерево переросло полный перебор (363 тыс. → 34 млн траекторий). SELFTEST перестроен: estimate() оценивает число траекторий произведением средних чисел выборов по сценам (мемоизируется в _est); survey() идёт полным обходом, пока влезает в fullBudget = 1 200 000, дальше переходит на walkSample. Отчёт ПРЯМО пишет «обход: ПОЛНЫЙ — достижимость доказана» либо «ВЫБОРКА — оценена, не доказана», и вместо «НЕДОСТИЖИМА» печатает «не встретилась в выборке». Подменять гарантию молчанием нельзя
  • probeBudget = 300: text() и chronicle() дёргаются не более 300 раз на сцену — их проверяют на падение, и нескольких сотен разных состояний хватает
  • calibrate() мерил только ФИНАЛЬНЫЕ состояния и объявлял пустыми вполне живые полосы: QUALIA показывается каждый ход. Теперь собирает по всем ходам (survey(..., atEvery=true))
  • Полоса adamance «тверды, как стекло» (1–17) удалена: повесть через это состояние не проходит, первая удавшаяся силима сразу твёрже стали. Правильнее убрать полосу, чем подгонять под неё сюжет
  • Верхняя полоса нерушимости «нерушимы» (78+) достижима только через освящение Варды — заглушка акта V теперь даёт adamance +46, иначе полоса пустовала

Асимметрия хватки (введена в акте IV — ключевое правило модели)

  • Всё, что ПРИБАВЛЯЕТ хватки, входит в формулу как есть. Всё, что УБАВЛЯЕТ, входит с затуханием и не может дать больше сорока пяти: bias = gripBias >= 0 ? gripBias : -45 * (1 - Math.exp(gripBias / 45))
  • Смысл: открытость и щедрость способны замедлить хватку, но не отменить того, что вещь уже сделана. Без этого правила акт IV позволял свести хватку к нулю и тезис повести рушился
  • Проверено на 200 тыс. прохождений: среди лучшей четверти по качеству камней минимальная хватка 18, медиана 73; хватка ровно 0 выпадает в 0,34 % случаев и только при слабых камнях. Отличные камни и разжатая рука одновременно практически недостижимы — как и задумано
  • Занятость шкалы хватки после акта IV (по всем ходам): 30.2 % ничего не показывается (акты I–II, держать ещё нечего), далее 15.5 / 14.1 / 13.9 / 13.3 / 7.2 / 5.7. Пороги [0, 1, 30, 46, 58, 70, 79] менять не потребовалось
