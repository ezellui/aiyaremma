Грабли браузерных тестов (копилка 0.4)

  1. pkill-самострел: pkill -f "[v]ite" в одном bash-вызове с heredoc, содержащим «vite» плоско, убивает собственный шелл.
  2. npx-обёртка vite при SIGKILL оставляет сироту — спавнить node ../node_modules/vite/bin/vite.js (бинарь в КОРНЕВОМ node_modules, client/node_modules пуст).
  3. d3 raise() в hover переставляет .node-g в конец DOM — nth-адресация врёт; адресоваться по g.data.name.
  4. Заголовки панелей капсятся CSS-ом — innerText отдаёт визуальный регистр, сверять через toUpperCase() (родня грабли 1.5).
  5. У РЁБЕР 3D тоже тултип (desc+[тип], без имён узлов) — охоту на узлы фильтровать по списку имён.
  6. Клик/tap по хитбоксу ребра НЕ ставит isOrbit (поведение порта) — orbit-жест начинать из заведомо пустой точки (elementFromPoint=canvas И тултип не зажёгся).
  7. Раскладка-«кольцо»: при zoom 150 узлы разлетаются к краям канваса, центр бывает пуст — сетку охоты строить ОТНОСИТЕЛЬНОЙ (доли rect до ±0.4).
  8. CDP Input.dispatchTouchEvent работает (headless shell + SwiftShader): двухточечный touchStart Chrome разбивает на touchstart:1+touchstart:2 (пинчу не мешает); touchEnd с пустым touchPoints корректен.
  9. Шпион touch-событий вешать на document с capture и логом e.target.tagName — мгновенно вскрывает перекрытия (события шли @SPAN/@DIV легенды).
  10. Фоновая страница: bringToFront + флаги --disable-background-timer-throttling/--disable-backgrounding-occluded-windows/--disable-renderer-backgrounding (rAF-диагностика: счётчик кадров за 500мс).
  11. Сценарный catch со стеком ОБЯЗАТЕЛЕН до finally с process.exit — иначе исключение глотается молча.
