# Claude Service

Сервис интеграции с Claude API для платформы философских концепций.

## Возможности

- Интеграция с Anthropic Claude API
- Форматирование сложных философских запросов
- Поддержка пользовательских API ключей
- Отслеживание использования и затрат
- Кэширование API ключей
- Полная история взаимодействий

## Типы запросов

### Работа с графами
- Валидация графа концепции
- Обогащение категорий
- Обогащение связей между категориями
- Анализ происхождения концепции

### Работа с тезисами
- Генерация тезисов из графа
- Генерация графа из тезисов
- Анализ происхождения тезисов

### Синтез и совместимость
- Синтез двух концепций
- Анализ совместимости концепций
- Критика синтезированной концепции

### Диалоги
- Создание философских диалогов между концепциями
- Поддержка различных форматов (платоновский, современный, дебаты)

### Исторический и практический анализ
- Историческая контекстуализация
- Анализ практических применений
- Анализ возможной эволюции концепции

### Работа с названиями
- Генерация названий для концепций
- Анализ соответствия названия концепции
