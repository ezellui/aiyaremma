# Concept Service

Сервис управления философскими концепциями для платформы философских концепций.

## Возможности

- CRUD операции для концепций
- Управление философами и традициями
- Связывание концепций с философами и традициями
- Полнотекстовый поиск концепций
- Поиск по тегам
- Расширенный поиск с фильтрами
- Поиск похожих концепций через Neo4j
- Статистика концепций
- Интеграция с Neo4j для графовых данных
