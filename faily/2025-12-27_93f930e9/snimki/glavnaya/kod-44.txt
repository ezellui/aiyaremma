
## Использование

1. Скопируйте папку service-template
2. Переименуйте в имя вашего сервиса
3. Обновите package.json (name, description)
4. Обновите .env переменные
5. Добавьте специфичную логику в контроллеры и сервисы

## Команды

```bash
# Разработка
npm run dev

# Продакшн
npm start

# Тесты
npm test

# Линтинг
npm run lint
