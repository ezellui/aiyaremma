# Neo4j Initialization

Этот файл содержит Cypher скрипты для инициализации Neo4j графовой базы данных.

## Выполнение скриптов

### Вариант 1: Через Neo4j Browser
1. Откройте Neo4j Browser (http://localhost:7474)
2. Скопируйте и выполните содержимое `init-constraints.cypher`

### Вариант 2: Через cypher-shell
```bash
cat init-constraints.cypher | cypher-shell -u neo4j -p password
