# Graph Service

Сервис управления графами категорий философских концепций для платформы философских концепций.

## Возможности

- CRUD операции для графов концепций
- Управление категориями и связями между ними
- Вычисление центральности узлов
- Анализ структуры графа
- Поиск путей между категориями
- Обнаружение циклов
- Экспорт графов в различные форматы
- Интеграция с Claude для валидации и обогащения
