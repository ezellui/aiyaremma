# API Gateway

Единая точка входа для всех API запросов платформы философских концепций.

## Возможности

- JWT аутентификация
- Rate limiting с использованием Redis
- Проксирование запросов к микросервисам
- Централизованное логирование
- Обработка ошибок
- CORS и безопасность
