# API Gateway

Единая точка входа для всех API-запросов в платформе философских концепций.

## Функциональность

- Аутентификация и авторизация
- Rate limiting
- Проксирование запросов к микросервисам
- Кэширование ответов
- Логирование запросов
- Обработка ошибок

## API Endpoints

### Аутентификация (`/api/auth`)
- `POST /register` - Регистрация
- `POST /login` - Вход
- `POST /logout` - Выход
- `POST /refresh` - Обновление токена
- `GET /me` - Текущий пользователь

### Управление пользователями (`/api/users`)
- `GET /:id` - Получение данных пользователя
- `PUT /:id` - Обновление данных
- `GET /:id/activity` - Активность пользователя
- `POST /:id/api-key` - Установка ключа API Claude
- `DELETE /:id/api-key` - Удаление ключа API
- `GET /:id/api-key/usage` - Статистика использования
- `POST /:id/api-key/share` - Создание совместного доступа
- `GET /:id/shared-keys` - Получение общих ключей
- `DELETE /:id/api-key/share/:shareId` - Отзыв доступа

### Концепции (`/api/concepts`)
- `GET /` - Список концепций
- `GET /:id` - Получение концепции
- `POST /` - Создание концепции
- `PUT /:id` - Обновление концепции
- `DELETE /:id` - Удаление концепции
- `POST /:id/name` - Установка названия

### Графы (`/api/graphs`)
- `GET /concepts/:conceptId` - Граф концепции
- `GET /categories/:id` - Получение категории
- `POST /concepts/:conceptId/categories` - Создание категории
- `PUT /categories/:id` - Обновление категории
- `DELETE /categories/:id` - Удаление категории
- `POST /categories/:id/enrich` - Обогащение категории
- `GET /relationships/:id` - Получение связи
- `POST /relationships` - Создание связи
- `PUT /relationships/:id` - Обновление связи
- `DELETE /relationships/:id` - Удаление связи
- `POST /relationships/:id/enrich` - Обогащение связи
- `POST /from-theses` - Генерация графа из тезисов
- `GET /concepts/:conceptId/characteristics` - Характеристики графа
- `POST /categories/:id/characteristics` - Обновление характеристик категории
- `POST /relationships/:id/characteristics` - Обновление характеристик связи
- `POST /categories/:id/characteristics/metadata` - Метаданные характеристик
- `POST /relationships/:id/characteristics/metadata` - Метаданные характеристик
- `GET /templates/categories` - Шаблоны категорий
- `GET /templates/relationships` - Шаблоны типов связей
- `GET /generated-elements/:conceptId` - Новые элементы для одобрения
- `POST /generated-elements/approve` - Одобрение элементов

### Тезисы (`/api/theses`)
- `GET /concepts/:conceptId` - Тезисы концепции
- `GET /:id` - Получение тезиса
- `POST /concepts/:conceptId` - Генерация тезисов
- `POST /concepts/:conceptId/generate-with-characteristics` - Генерация с характеристиками
- `PUT /:id` - Обновление тезиса
- `DELETE /:id` - Удаление тезиса
- `POST /:id/elaborate` - Обоснование тезиса
- `POST /compare` - Сравнение тезисов
- `POST /analyze-origin` - Анализ происхождения

### Синтез (`/api/synthesis`)
