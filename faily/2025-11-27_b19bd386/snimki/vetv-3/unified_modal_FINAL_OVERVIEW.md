## 🎯 ОСНОВНЫЕ ИЗМЕНЕНИЯ

### Структура HTML

**БЫЛО (5 разных модальных окон):**
```html
<div id="detailModal">...</div>
<div id="philosopherDetailModal">...</div>
<div id="editPhilosopherModal" class="edit-modal">...</div>
<div id="editConceptModal" class="edit-modal">...</div>
<div id="editConnectionModal" class="edit-modal">...</div>
```

**СТАЛО (1 универсальное окно):**
```html
<div id="universalModal" class="detail-modal">
    <button class="mode-switch-btn" onclick="toggleModalMode()">
        <span id="modeIcon">✏️</span> 
        <span id="modeText">Редактировать</span>
    </button>
    <button class="modal-close" onclick="closeUniversalModal()">×</button>
    <div id="universalModalContent" class="modal-content"></div>
</div>
```

### CSS классы

**Основные замены:**
- `.edit-modal` → `.detail-modal`
- `.edit-form-group` → `.modal-form-group`
- `.edit-modal-actions` → `.modal-actions`
- `.edit-btn` → `.modal-btn`
- `.edit-list-section` → `.modal-edit-section`
- `.concept-search-container` → `.modal-concept-search`

**Новые классы:**
- `.mode-switch-btn` - кнопка переключения режимов
- `.detail-modal.edit-mode` - индикатор режима редактирования
- `.collapsible-section` - сворачиваемые секции
- `.modal-divider` - разделитель
- `.modal-hint` - подсказка
- `.modal-status-badge` - статусный значок

## 📊 СТАТИСТИКА ИЗМЕНЕНИЙ

- **HTML:** 5 модальных окон → 1 универсальное окно

- ✨ Единообразный интерфейс для всех типов сущностей
- ✨ Статусные значки и подсказки

## 🔧 ЭТАПЫ ВНЕДРЕНИЯ

### Этап 1: Стили (10 минут)
1. Открыть `philosophy_graph_full__.html`
2. Найти строку 489 (начало стилей модальных окон)
3. Удалить строки 489-1626
4. Вставить содержимое `unified_modal_styles_COMPLETE.css`

### Этап 2: HTML структура (5 минут)
1. Найти строку ~1634 (модальные окна)
2. Удалить все 5 модальных окон
3. Вставить новую структуру из `unified_modal_HTML_EXAMPLES.md` (раздел 1)

### Этап 3: JavaScript архитектура (30 минут)
1. Создать `ModalContext` объект
2. Реализовать `openUniversalModal(entityType, data, mode)`
3. Реализовать `closeUniversalModal()`
4. Реализовать `toggleModalMode()`

### Этап 4: Генераторы контента (60 минут)
1. `generatePhilosopherViewContent()` - использовать шаблон из раздела 4
2. `generatePhilosopherEditContent()` - использовать шаблон из раздела 5
3. `generateConceptViewContent()` - использовать шаблон из раздела 2
4. `generateConceptEditContent()` - использовать шаблон из раздела 3
5. `generateConnectionViewContent()` - использовать шаблон из раздела 6
6. `generateConnectionEditContent()` - использовать шаблон из раздела 7

### Этап 5: Обновление вызовов (20 минут)
1. Найти все вызовы старых функций открытия окон
2. Заменить на `openUniversalModal()`
3. Использовать чеклист из `unified_modal_styles_CHEATSHEET.md`

### Этап 6: Тестирование (30 минут)
1. Протестировать просмотр концепций
2. Протестировать редактирование концепций
3. Протестировать просмотр философов
4. Протестировать редактирование философов
5. Протестировать просмотр связей
6. Протестировать редактирование связей
7. Протестировать переключение режимов
8. Протестировать сворачиваемые секции

**Общее время: ~2.5 часа**

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Что НЕ нужно менять:
- Стили для графа (nodes, links)
- Стили для легенды
- Стили для поиска в легенде
- Базовые стили body и container

### Что ОБЯЗАТЕЛЬНО нужно сделать:
- Заменить все 5 модальных окон на 1
- Обновить все классы в генераторах контента
- Реализовать функцию `toggleModalMode()`
- Обновить все вызовы открытия модальных окон

### Потенциальные проблемы:
- Если забыть обновить классы в генераторах, стили не применятся
- Если не реализовать `toggleModalMode()`, кнопка переключения не будет работать
- Если не обновить вызовы, старые функции будут выдавать ошибки
