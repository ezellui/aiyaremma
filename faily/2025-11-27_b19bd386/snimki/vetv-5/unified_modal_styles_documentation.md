# Документация по стилям унифицированной системы модальных окон

## Обзор

Это исчерпывающая коллекция CSS стилей для универсальной модальной системы, которая поддерживает:
- **3 типа сущностей**: философы, концепции, связи
- **2 режима работы**: просмотр (view) и редактирование (edit)
- **Единую архитектуру** для всех модальных окон

---

## Структура стилей

Файл стилей разделён на 18 логических секций:

### 1. Базовые стили модального окна (строки 1-65)
- `.detail-modal` - основной контейнер
- `.detail-modal.show` - видимое состояние
- `@keyframes modalFadeIn` - анимация появления
- `#modalOverlay` - затемнение фона

**Ключевые параметры:**
- Размеры: `max-width: 650px`, `max-height: 85vh`
- Позиционирование: центрирование через `transform: translate(-50%, -50%)`
- Z-index: `2000` (окно), `1999` (оверлей)

### 2. Режим редактирования (строки 67-82)
- `.detail-modal.edit-mode` - индикатор режима
- `.detail-modal.edit-mode::before` - метка "✏️ Режим редактирования"

**Визуальные отличия:**
- Фиолетовая рамка: `border-color: #a29bfe`
- Светящаяся тень: `box-shadow: 0 10px 40px rgba(162, 155, 254, 0.4)`
- Дополнительный отступ сверху для заголовков

### 3. Элементы контента (строки 84-130)
Общие элементы для обоих режимов:
- `h2`, `h3` - заголовки
- `.philosopher-tag` - теги философов с hover эффектом
- `.description` - текстовые описания

**Особенности:**
- Все теги философов кликабельны (cursor: pointer)
- Теги увеличивают непрозрачность при наведении

### 4. Кнопки управления (строки 132-178)
- `.modal-close` / `.close-btn` - кнопка закрытия (X)
- `.mode-switch-btn` - переключение view ↔ edit

**Позиционирование:**
- Кнопка закрытия: `top: 12px, right: 12px`
- Кнопка переключения: `top: 12px, right: 50px`
- Оба имеют `z-index: 10` для отображения над контентом

### 5. Scrollbar (строки 180-197)
Кастомная прокрутка в фиолетовых тонах:
- Ширина: `6px`
- Цвет: `#a29bfe` (основной), `#8b7fe6` (hover)

### 6. Рубрики (строки 199-250)
Специальные секции для концепций:
- `.rubric-section` - контейнер с левой фиолетовой границей
- `.rubric-title` - заголовок рубрики
- `.rubric-description` - описание рубрики (курсив, приглушённый цвет)
- `.rubric-name-tooltip` - подсказка с названием рубрики

**Важно:** Рубрики показываются только в режиме просмотра концепции!

### 7. Списки концепций (строки 252-308)
Общие стили для списков связанных концепций:
- `.concept-item` - элемент списка с hover эффектом (сдвиг вправо)
- `.concept-color` - цветовой индикатор (круг с тенью)
- `.concept-name` - название
- `.concept-philosopher` - имя философа (мелкий текст, курсив)

### 8. Секция концепций философа (строки 310-385)
Специфичные стили для окна философа:
- `.philosopher-concepts-list` - контейнер всех концепций
- `.philosopher-concept-item` - элемент концепции
- `.toggle-concept-desc-btn` - кнопка раскрытия описания
- `.concept-extended-desc` - развёрнутое описание (скрыто по умолчанию)
- `.toggle-all-descriptions-btn` - кнопка "Развернуть все"

**Состояния:**
- Скрыто: `display: none`
- Показано: `.show` класс → `display: block`
- Кнопка активна: `.expanded` класс

### 9. Связи (строки 387-492)
Самая сложная секция с подсекциями:

**Структура:**
```
.connections-section
  └── .connections-subsection (внутренние/внешние)
        ├── .subsection-header (кликабельный)
        │     ├── .subsection-title
        │     └── .subsection-toggle (стрелка)
        └── .subsection-content (сворачиваемый)
              └── .connection-item
                    ├── .connection-arrow (тип связи)
                    │     └── .connection-arrow-tooltip
                    ├── .connection-toggle (кнопка раскрытия)
                    └── .connection-description (скрыто по умолчанию)
```

**Ключевые особенности:**
- Стрелка поворачивается на 90° при сворачивании
- Подсказка типа связи появляется при наведении на стрелку
- Описания связей разворачиваются индивидуально

### 10. Формы редактирования (строки 494-584)
Все поля форм для режима edit:
- `.modal-form-group` - группа полей
- Типы полей: `text`, `number`, `color`, `select`, `textarea`
- `.modal-form-checkbox` - чекбоксы
- `.modal-form-inline` - горизонтальное расположение полей

**Стили при фокусе:**
- Фиолетовая рамка: `border-color: #a29bfe`
- Увеличенная прозрачность фона
- Плавный переход через `transition: all 0.3s`

### 11. Кнопки действий (строки 586-635)
Три типа кнопок:
- `.modal-btn-primary` - основная (Сохранить) - фиолетовая
- `.modal-btn-secondary` - вторичная (Отмена) - серая
- `.modal-btn-danger` - опасная (Удалить) - красная

**Hover эффекты:**
- Сдвиг вверх: `transform: translateY(-2px)`
- Светящаяся тень соответствующего цвета

### 12. Списки в режиме редактирования (строки 637-703)
Специальные стили для редактируемых списков:
- `.modal-edit-list` - контейнер
- `.modal-edit-list-item` - элемент с кнопками действий
- `.modal-edit-list-btn` - кнопка удаления (красная)
- `.modal-edit-list-btn-add` - кнопка добавления (зелёная)

**Отличие от view режима:**
- В view режиме используются обычные `.concept-item`
- В edit режиме используются `.modal-edit-list-item` с кнопками

### 13. Поиск концепций (строки 705-757)
Компонент поиска для форм редактирования связей:
- `.modal-concept-search` - контейнер (relative)
- `.modal-concept-search-results` - выпадающий список результатов
- `.modal-concept-search-item` - элемент результата

**Особенности:**
- Выпадающий список позиционирован абсолютно
- Показывается/скрывается через `.show` класс
- Имеет свой scrollbar

### 14. Заголовки и разделители (строки 759-788)
Вспомогательные элементы:
- `.modal-section-title` - заголовок секции с нижней границей
- `.section-title-with-count` - заголовок с счётчиком
- `.section-count` - бейдж с числом

### 15. Режим выбора на графе (строки 790-832)
Индикатор активного выбора концепций:
- `.graph-selection-mode` - плавающее окно справа вверху
- `.graph-selection-cancel` - кнопка отмены
- `@keyframes slideInRight` - анимация появления справа

**Когда показывается:**
- При редактировании связи и выборе source/target концепции
- Исчезает после выбора или отмены

### 16. Предупреждающие сообщения (строки 834-858)
Блоки предупреждений:
- `.warning-message` - жёлтый блок с рамкой
- `.warning-list` - список предупреждений

**Применение:**
- Валидационные ошибки
- Предупреждения о удалении
- Конфликты данных

### 17. Адаптивность (строки 860-883)
Media query для мобильных устройств:
- Увеличение ширины окна до `95%`
- Кнопка переключения режима перемещается вниз
- Инлайн формы становятся вертикальными

### 18. Утилитарные классы (строки 885-935)
Вспомогательные классы для быстрой стилизации:
- `.hidden` - скрыть элемент
- `.text-ellipsis` - обрезка текста с многоточием
- `.divider` - горизонтальная линия
- `.font-bold`, `.font-italic` - стили текста
- `.text-small`, `.text-muted` - размер и цвет
- `.mt-10`, `.mb-15` и т.д. - отступы

## Адаптация к новой системе

### Что изменилось по сравнению с прежней системой

#### 1. Унификация ID и классов

**Было (старая система):**
```css
#detailModal { ... }                    /* Окно концепции */
#philosopherDetailModal { ... }         /* Окно философа */
#editPhilosopherModal { ... }           /* Редактирование философа */
#editConceptModal { ... }               /* Редактирование концепции */
#editConnectionModal { ... }            /* Редактирование связи */
```

**Стало (новая система):**
```css
.detail-modal { ... }                   /* Единое окно для всех */
.detail-modal.edit-mode { ... }         /* Режим редактирования */
```

#### 2. Объединение стилей просмотра и редактирования

**Было:**
- Отдельные стили `.edit-modal` для форм
- Дублирование базовых стилей

**Стало:**
- Единый `.detail-modal` с модификатором `.edit-mode`
- Общие стили применяются к обоим режимам
- Специфичные стили только для уникальных элементов

#### 3. Новые элементы

**Добавлено:**
- `.mode-switch-btn` - кнопка переключения режимов
- `.detail-modal.edit-mode::before` - индикатор режима
- `.modal-concept-search` - поиск концепций (вместо `.concept-search-container`)
- Префикс `.modal-` для всех компонентов форм

### Миграция стилей из старого кода

#### Рубрики
✅ **Сохранены без изменений**
- `.rubric-section`
- `.rubric-title`
- `.rubric-description`

#### Секция философа
✅ **Адаптированы и улучшены**
- Добавлены стили из `philosopher_detail_modal_OPTIMAL.md`
- Все стили для концепций философа и связей

#### Формы редактирования
✅ **Переименованы с префиксом `.modal-`**
- `.edit-form-group` → `.modal-form-group`
- `.edit-form-checkbox` → `.modal-form-checkbox`
- `.edit-btn` → `.modal-btn`
- `.edit-list-item` → `.modal-edit-list-item`

#### Поиск концепций
✅ **Переименован с префиксом `.modal-`**
- `.concept-search-container` → `.modal-concept-search`
- `.concept-search-input` → `input` внутри `.modal-concept-search`
- `.concept-search-results` → `.modal-concept-search-results`
- `.concept-search-item` → `.modal-concept-search-item`

## Рекомендации по использованию

### 1. Не модифицировать базовые классы

**Правильно:**
```css
/* Добавить специфичный класс */
.detail-modal.my-custom-modal {
    max-width: 800px;
}
```

**Неправильно:**
```css
/* Изменять базовый класс */
.detail-modal {
    max-width: 800px; /* Это повлияет на все окна! */
}
```

### 2. Использовать утилитарные классы

**Вместо:**
```html
<div style="margin-top: 20px; font-weight: 700;">
```

**Лучше:**
```html
<div class="mt-20 font-bold">
```

### 3. Следовать иерархии классов

**Правильная вложенность:**
```html
<div class="detail-modal edit-mode">
    <div class="modal-form-group">
        <label>Название</label>
        <input type="text">
    </div>
    <div class="modal-actions">
        <button class="modal-btn modal-btn-primary">Сохранить</button>
        <button class="modal-btn modal-btn-secondary">Отмена</button>
    </div>
</div>
```

### 4. Использовать семантические классы

Классы названы так, чтобы отражать их назначение:
- `.modal-form-group` - группа полей формы
- `.connection-item` - элемент связи
- `.philosopher-tag` - тег философа

### 5. Соблюдать режимы

**Только в режиме view:**
- `.rubric-section` - рубрики
- `.related-concepts` - списки связанных концепций (только чтение)

**Только в режиме edit:**
- `.modal-form-group` - поля форм
- `.modal-edit-list` - редактируемые списки
- `.modal-actions` - кнопки действий

**В обоих режимах:**
- `.connections-section` - связи (с разными функциями)
- `.philosopher-concepts-list` - концепции философа

## Troubleshooting (решение проблем)

### Проблема: Окно не центрируется
**Решение:** Проверьте, что не переопределён `transform: translate(-50%, -50%)`

### Проблема: Стили не применяются
**Решение:** 
1. Убедитесь, что класс `.detail-modal` добавлен к окну
2. Проверьте, что нет конфликтующих стилей с более высоким приоритетом
3. Проверьте порядок загрузки CSS

### Проблема: Режим редактирования не отображается
**Решение:** Убедитесь, что добавлен класс `.edit-mode` к `.detail-modal`

### Проблема: Scrollbar не стилизуется
**Решение:** Стили scrollbar работают только в WebKit браузерах (Chrome, Safari, Edge)

### Проблема: Анимации не работают
**Решение:** Проверьте, что CSS анимации не отключены в браузере или системе

## Расширение системы

### Добавление нового типа сущности

Если нужно добавить новый тип сущности (например, "категория"):

1. **JavaScript:** Добавить в `openUniversalModal()` новый case:
```javascript
case 'category':
    html = mode === 'view' 
        ? generateCategoryViewContent(data)
        : generateCategoryEditContent(data);
    break;
```

2. **CSS:** Использовать существующие классы или добавить специфичные:
```css
/* Специфичные стили для категории */
.detail-modal .category-specific-element {
    /* стили */
}
```

### Добавление нового режима

Если нужен третий режим (например, "preview"):

1. **CSS:** Добавить модификатор:
```css
.detail-modal.preview-mode {
    max-width: 800px;
    /* специфичные стили */
}
```

2. **JavaScript:** Обработать новый режим в `openUniversalModal()`
