# ✅ РЕШЕНИЕ: Проблема с прокруткой модального окна

## 🎯 Что было исправлено

Вы правильно заметили проблему - **содержимое окна не прокручивалось до конца** при большом количестве связей.

### 🔍 Причина
Отсутствовал `box-sizing: border-box`, из-за чего:
- Padding (25px × 2 = 50px) добавлялся СВЕРХ max-height
- Окно реально занимало 85vh + 50px вместо 85vh
- Scrollbar не доходил до конца контента

### ✅ Решение (v1.2)

**5 исправлений применены:**

1. ✅ **Добавлен box-sizing**
   ```css
   .detail-modal {
       box-sizing: border-box; /* padding теперь ВНУТРИ max-height */
   }
   ```

2. ✅ **Универсальное box-sizing для всех элементов**
   ```css
   .detail-modal * { box-sizing: border-box; }
   ```

3. ✅ **Увеличен max-height**
   ```css
   max-height: 90vh; /* было 85vh, +50px для контента */
   ```

4. ✅ **Уменьшен margin в edit-mode**
   ```css
   margin-top: 12px; /* было 20px, +8px для контента */
   ```

5. ✅ **Добавлен padding-bottom**
   ```css
   .modal-content {
       padding-bottom: 10px; /* визуальный комфорт */
   }
   ```
