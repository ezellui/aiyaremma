## 🎨 Ключевые концепции новой системы

### 1. Единое модальное окно
```html
<div id="universalModal" class="detail-modal">
    <!-- Контент генерируется динамически -->
</div>
```

### 2. Режимы через модификаторы
```javascript
// Режим просмотра
modal.classList.remove('edit-mode');

// Режим редактирования
modal.classList.add('edit-mode');
```

### 3. Универсальная функция открытия
```javascript
openUniversalModal(entityType, data, mode);

// Примеры:
openUniversalModal('philosopher', 'Кант', 'view');
openUniversalModal('concept', conceptData, 'edit');
openUniversalModal('connection', connData, 'edit');
```

### 4. Общие стили для всех типов
```css
.detail-modal { /* общие стили */ }
.detail-modal.edit-mode { /* стили редактирования */ }
.detail-modal .concept-item { /* общие элементы */ }
```

## 🐛 Известные проблемы и решения

### CSS не загружается
**Проблема:** Стили не применяются после вставки  
**Решение:** Проверьте, что CSS вставлен внутри тега `<style>`, а не после него

### JavaScript ошибки
**Проблема:** `openUniversalModal is not defined`  
**Решение:** Убедитесь, что функция определена до её вызова

### Контент не генерируется
**Проблема:** Пустое модальное окно  
**Решение:** Проверьте, что генераторы контента реализованы и возвращают HTML

### Режим редактирования не работает
**Проблема:** Класс `.edit-mode` не меняет стили  
**Решение:** Убедитесь, что CSS правило `.detail-modal.edit-mode` присутствует
