## 🎯 Ключевые особенности решения

### 1. Полное покрытие
Адаптированы **все** стили из исходных файлов:
- ✅ Рубрики (для концепций)
- ✅ Секция взаимодействия философов
- ✅ Выбор концепций на графе
- ✅ Формы редактирования
- ✅ Режим просмотра
- ✅ Связи и подсекции
- ✅ Scrollbar и анимации

### 2. Унификация через классы
Вместо ID селекторов используются классы:
```css
/* Было */
#detailModal { ... }
#philosopherDetailModal { ... }
#editPhilosopherModal { ... }

/* Стало */
.detail-modal { ... }
.detail-modal.edit-mode { ... }
```

### 3. Модульность
Каждая секция независима и может быть изменена отдельно:
- Изменения в стилях рубрик не влияют на связи
- Изменения в формах не влияют на просмотр
- Добавление новых элементов не требует переписывания существующих

### 4. Префикс `.modal-` для форм
Все компоненты форм получили единый префикс:
```css
.modal-form-group      /* вместо .edit-form-group */
.modal-form-checkbox   /* вместо .edit-form-checkbox */
.modal-btn             /* вместо .edit-btn */
.modal-edit-list       /* вместо .edit-list-section */
.modal-concept-search  /* вместо .concept-search-container */
```

### 5. Состояния через `.show` класс
Единый механизм показа/скрытия:
```css
.element { display: none; }
.element.show { display: block; }
```

## 🎨 Стилистические решения

### Цветовая палитра
- **Акцент:** `#a29bfe` (фиолетовый) - единый для всей системы
- **Фон:** `rgba(0, 0, 0, 0.92)` - тёмный с прозрачностью
- **Текст:** `#e0e0e0` (светло-серый) для читаемости
- **Hover эффекты:** Увеличение яркости и сдвиг элементов

### Анимации
- Появление окна: 0.3s fade + slide
- Hover переходы: 0.2-0.3s плавные
- Вращение кнопки закрытия: 90° при hover
- Pulse анимация для активных элементов

### Типографика
- Заголовки: 22px (h2), 18px (h3)
- Основной текст: 13-14px
- Мелкий текст: 10-12px
- Line-height: 1.5-1.6 для читаемости
