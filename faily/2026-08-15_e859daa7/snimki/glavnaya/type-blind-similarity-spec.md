# Типослепое сходство концепций: точная формула

Мера, которой в этой беседе проверялось, держится ли смещение по традициям без
типов связей. Даёт 107 пар «дуга + связь», 46 межфилософских, 65,2 %
межтрадиционных, ρ(степень, верхнее сходство) = −0,325.

Устройство намеренно повторяет `similarityData()`: z-нормировка поперёк корпуса,
двойное центрирование, косинус. Отличие ровно одно — **ни один признак не смотрит
на `r.type`**.

---

## 0. Граф, на котором всё считается

Множество концепций `V`, |V| = n = 453. Рёбра берутся из `_relations`
(то есть из проекции для метрик, а не из `links`, испорченных d3), причём:

- **петли отброшены**: рёбра с `source === target` не участвуют (их 23);
- вес `w(e) = r.weight || 1`;
- ребро считается **симметричным**, если `isSymmetricLink(r)` — это функция
  приложения, и она смотрит на `r.bidirectional`, а не на тип.

Из них строятся три структуры:

| обозначение | что это |
|---|---|
| `Out(i)` | мультимножество целей рёбер, выходящих из i; для симметричного ребра i добавляется и в `Out(j)`, и наоборот |
| `In(i)` | двойственно |
| `N(i)` | **неориентированное** множество соседей: j ∈ N(i) ⟺ есть ребро i—j в любую сторону |

Веса: `wIn(i) = Σ w(e)` по входящим (симметричные считаются в обе стороны),
`wOut(i)` двойственно.

Все расстояния и обходы дальше — по **неориентированному** графу `N`.

---

## 1. Семнадцать признаков

Для каждой концепции i строится вектор `f(i) ∈ ℝ¹⁷`.

| № | признак | определение |
|---|---|---|
| 1 | степень | \|N(i)\| |
| 2 | вход | \|In(i)\| |
| 3 | выход | \|Out(i)\| |
| 4 | вес входа | wIn(i) |
| 5 | вес выхода | wOut(i) |
| 6 | PageRank прямой | PR по `Out` (см. §1.1) |
| 7 | PageRank обращённый | PR по `In` |
| 8 | кластеризация | 2·L(i) / (\|N(i)\|·(\|N(i)\|−1)), где L(i) — число рёбер между соседями i; при \|N(i)\| < 2 равна 0 |
| 9 | соседи на 2 шага | \#{ j : d(i,j) = 2 }, d — кратчайшее расстояние в N |
| 10 | средняя степень соседа | (1/\|N(i)\|)·Σ_{j∈N(i)} \|N(j)\| ; при N(i) = ∅ равна 0 |
| 11 | философов рядом | \|{ φ(j) : j ∈ N(i) }\|, φ — автор концепции |
| 12 | внутренних соседей | \#{ j ∈ N(i) : φ(j) = φ(i) } |
| 13 | внешних соседей | \#{ j ∈ N(i) : φ(j) ≠ φ(i) } |
| 14 | соседей раньше | \#{ j ∈ N(i) : b(φ(j)) < b(φ(i)) }, b — год рождения |
| 15 | соседей позже | \#{ j ∈ N(i) : b(φ(j)) > b(φ(i)) } |
| 16 | средняя дата соседей | ( среднее b(φ(j)) по j ∈ N(i) − b(φ(i)) ) / 100 |
| 17 | разброс дат соседей | ( σ от b(φ(j)) по j ∈ N(i) ) / 100 |

Деления на 100 в 16–17 (и умножение PageRank на 1000 в первой реализации)
**на результат не влияют**: следующий шаг z-нормирует каждый столбец, а
z-оценка инвариантна к линейному масштабированию. Оставлены только для
читаемости промежуточных распечаток.

### 1.1 PageRank

Стандартный, с затуханием d = 0,85 и 40 итерациями, с разбросом висячих узлов:

    v⁰ = 1/n
    vᵗ⁺¹(j) = (1−d)/n + d · ( Σ_{i : j ∈ A(i)} vᵗ(i)/|A(i)|  +  D_t/n )
    D_t = Σ_{i : A(i) = ∅} vᵗ(i)

`A = Out` даёт признак 6, `A = In` — признак 7.

### 1.2 Признаки, которые проверялись и НЕ вошли

Посредничество, близость, эксцентриситет, собственный вектор, взвешенная
кластеризация по Барра, rich-club, локальная когезия. Все семь измерены; ни один
не улучшил меру (см. `graph-metrics-in-profile.md`): зависимость от степени росла
с −0,325 до −0,422, устойчивость падала с 0,358 до 0,294. Посредничество, близость
и собственный вектор — переодетая степень (ρ = 0,93 / 0,98 / 0,93 с уже имеющимися
признаками) и втрое утяжеляют вес связности в равноправном наборе.

## 2. Двойное центрирование

Пусть `F` — матрица n × 17, `F[i][k] = f_k(i)`.

**Шаг 1 — z-нормировка по столбцу** (поперёк корпуса, как в приложении):

    μ_k = (1/n) Σ_i F[i][k]
    σ_k = sqrt( (1/n) Σ_i (F[i][k] − μ_k)² )        ← делитель n, не n−1
    Z[i][k] = (F[i][k] − μ_k) / σ_k                  ← при σ_k = 0 берётся σ_k := 1

**Шаг 2 — центрирование по строке**:

    m_i = (1/17) Σ_k Z[i][k]
    V[i][k] = Z[i][k] − m_i

**Шаг 3 — норма строки**:

    ‖V_i‖ = sqrt( Σ_k V[i][k]² )

## 3. Само сходство

    sim(a, b) = ( Σ_k V[a][k] · V[b][k] ) / ( ‖V_a‖ · ‖V_b‖ )   при ‖V_a‖·‖V_b‖ ≠ 0
    sim(a, b) = 0                                                иначе

Из-за шага 2 (нулевое среднее у каждой строки) косинус здесь **тождественно равен
корреляции Пирсона между профилями a и b по семнадцати признакам**. Сравнивается
форма профиля, а не величина: концепция с двадцатью связями и концепция с пятью
могут иметь sim = 1, если их признаки отклоняются от корпусных средних в одну
сторону и в одинаковых пропорциях.

Диапазон: [−1, 1]. Отрицательные значения содержательны (противоположная форма),
но при отборе шестёрки отбрасываются — см. §4.

## 4. Отбор шестёрки (в точности как `showSimilarityOverlay`)

    nearest(a) = первые 6 из { b ≠ a : sim(a,b) > 0 },
                 упорядоченных по убыванию sim

Порядок при равных значениях — порядок перебора `ids`. Для этой меры ничьи почти
не встречаются (в отличие от жаккара, где у 181 концепции из 453 шестое место —
ничья): значения непрерывны.

**Отсева малосвязных нет** — сознательно, чтобы сравнение с картой приложения было
честным: `showSimilarityOverlay` тоже его не делает. Именно поэтому величина
ρ(степень, верхнее сходство) = −0,325 сопоставима с −0,466 у профиля приложения
без отсева, а не с −0,178 после отсева.

## 5. Свойства, замеренные на этой базе

| | значение |
|---|---|
| ρ(степень, верхнее сходство) | −0,325 (у профиля приложения −0,466) |
| устойчивость к выбросу 10 % связей (Жаккар шестёрок, 4 прогона) | 0,358 (у приложения 0,462) |
| пар «дуга + связь» | 107 (у приложения 88) |
| из них межфилософских | 46 (у приложения 29) |
| межтрадиционных среди них | 30 = 65,2 % (у приложения 11 = 37,9 %; фон 67,9 %) |
| переживают удаление собственного ребра | 74 из 107 = 69 % (у приложения 57 из 88 = 65 %) |

**Что мера умеет.** Снимать вклад разметки типов: именно ею показано, что смещение
по традициям у метрического профиля было артефактом словаря типов, а не фактом
об истории философии.

**Чего не умеет.** Она не лучше приложения как инструмент чтения: устойчивость ниже,
насыщение выше (77 концепций с верхним сходством ≥ 0,95 против 40). Её назначение —
контрольная мера, а не замена. На уровне философов аналогичная сборка оказалась
худшей из пяти и там не рекомендуется вовсе.

## 6. Оговорка о независимости

Типослепота снимает вклад **типов**, но не вклад **самого ребра**: признаки 1–17
читают структуру графа, а значит и то ребро, наличие которого потом проверяется.
Отсюда проверка «удали ребро между парой и пересчитай», которую надо делать
всегда: у этой меры выживает 69 % пар. Полностью свободна от круга только
жаккаровская мера приложения (100 %), и по причине устройства: ребро a—b не
добавляет общих соседей, оно меняет лишь объединение множеств.
