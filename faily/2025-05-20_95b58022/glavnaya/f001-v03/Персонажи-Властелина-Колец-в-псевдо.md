# Персонажи "Властелина Колец" в псевдографике

## Братство Кольца

### Фродо Бэггинс
```
       ,---.
      /  |  \
     /   |   \
    |  • - •  |
    |    ^    |
    | ╭─╯ ╰─╮ |
     \   o   /    ← Кольцо
     /|\ /|\
    / | V | \
      /   \
     /     \
   _/_______\_
  |___________|
```

Хранитель Кольца. Хоббит с большой ответственностью и внутренней силой.
"Я пойду в Мордор один, хотя я не знаю пути"
