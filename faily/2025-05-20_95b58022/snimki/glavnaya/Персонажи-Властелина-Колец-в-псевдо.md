# Персонажи "Властелина Колец" в псевдографике

## Братство Кольца

### Фродо Бэггинс
```
        _,,_
       /    \    ← Кудрявые 
      /  ,,  \      волосы хоббита
     /  /''\  \

    |  |  ◡  |  |    голубые глаза
    |  |_____|  |    и ясное лицо
     \  \___/  /
      \       /
       \ ___ /
       /|\ /|\
      / | V | \     ← На груди 
       /|_||\       ← цепочка
```

"Я пойду в Мордор один, хотя я не знаю пути"
