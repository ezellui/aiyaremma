# Инструкции по сборке приложения "Сервис философских концепций"

## Описание
Приложение разделено на 4 части для удобства обзора и модификации:
1. HTML структура и CSS стили (Часть 1)
2. Функции для работы с базой данных и API (Часть 2)
3. Функции для генерации тезисов и синтеза концепций (Часть 3)
4. Дополнительные функции и финализация (Часть 4)

## Процесс сборки

### Шаг 1: Создание основного файла
1. Создайте файл `philosophical-concepts.html`
2. Скопируйте содержимое из **Части 1 (HTML структура и CSS)** в этот файл

### Шаг 2: Добавление JavaScript кода
1. Найдите тег `<script>` в конце файла (перед `</body>`)
2. Добавьте код в следующем порядке:
   - Основной код из первого скрипта (уже в файле)
   - Код из **Части 2** (Работа с базой данных и API)
   - Код из **Части 3** (Генерация тезисов и синтез)
   - Код из **Части 4** (Дополнительные функции)

### Шаг 3: Финальная структура файла
Ваш HTML файл должен иметь следующую структуру:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <!-- Meta теги и стили -->
</head>
<body>
    <!-- HTML структура -->
    
    <script>
        // Часть 1: Основные структуры данных и функции
        // Часть 2: Работа с базой данных и API
        // Часть 3: Генерация тезисов и синтез
        // Часть 4: Дополнительные функции
    </script>
</body>
</html>
```

## Требования для работы

### 1. API ключ Claude
- Получите API ключ от Anthropic
- Введите его в соответствующее поле на странице

### 2. Локальное хранилище
- Приложение использует localStorage для хранения данных
- База данных сохраняется автоматически каждые 30 секунд

### 3. Современный браузер
- Chrome, Firefox, Safari или Edge последних версий
- Включенный JavaScript
- Разрешенные cookies и localStorage

## База данных

### Формат хранения
База данных хранится в localStorage в формате JSON со следующей структурой:
```json
{
    "concepts": [],
    "categories": [],
    "relations": [],
    "relationTypes": [],
    "apiKey": "your-api-key"
}
```

### Экспорт и импорт
- **Экспорт**: Нажмите кнопку "Экспорт базы данных" для сохранения в JSON файл
- **Импорт**: Нажмите кнопку "Импорт базы данных" и выберите JSON файл

## Основные функции

### 1. Работа с концепциями
- Создание новых концепций
- Добавление категорий и связей
- Визуализация графа концепции
- Валидация через Claude API

### 2. Генерация тезисов
- Выбор типа и стиля тезисов
- Учет количественных характеристик
- Сравнение версий тезисов

### 3. Синтез концепций
- Выбор метода синтеза
- Анализ совместимости
- Критический анализ результата

### 4. Дополнительный анализ
- Историческая контекстуализация
- Практическое применение
- Диалогическая интерпретация
- Эволюция концепции

## Рекомендации по использованию

1. **Начало работы**
   - Введите API ключ
   - Создайте новую концепцию или импортируйте существующую
   - Добавьте категории и установите связи между ними

2. **Работа с Claude**
   - Используйте функции валидации и обогащения
   - Генерируйте тезисы на основе графа
   - Экспериментируйте с синтезом концепций

3. **Сохранение работы**
   - Регулярно экспортируйте базу данных
   - Используйте функции экспорта для сохранения результатов анализа

## Решение проблем

### Частые ошибки
1. **Ошибка API**: Проверьте правильность ключа
2. **Пустой граф**: Убедитесь, что концепция выбрана
3. **Ошибка импорта**: Проверьте формат JSON файла

### Поддержка
При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Убедитесь, что API ключ действителен
3. Попробуйте перезагрузить страницу
4. Экспортируйте данные перед очисткой кэша
