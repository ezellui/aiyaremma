# Пример базы данных для Сервиса философских концепций

## Описание содержимого

Эта база данных содержит три классические философские концепции:

### 1. Платоновский идеализм
- **Категории**: Мир идей, Мир вещей, Душа, Благо
- **Основные связи**: Иерархическая структура от Блага к миру идей и далее к миру вещей
- **Ключевые философы**: Платон, Плотин, Августин

### 2. Трансцендентальный идеализм Канта
- **Категории**: Вещь в себе, Явление, Априорные формы, Категорический императив
- **Основные связи**: Диалектическая связь между вещью в себе и явлением
- **Ключевые философы**: Кант, Шопенгауэр, Фихте

### 3. Абсолютный идеализм Гегеля
- **Категории**: Абсолютный дух, Диалектика, Отчуждение, Снятие
- **Основные связи**: Функциональные и диалектические связи между категориями
- **Ключевые философы**: Гегель, Маркс, Брэдли

## Особенности примера

1. **Разнообразие философских систем**: Представлены три различные формы идеализма
2. **Полные метаданные**: Каждая категория содержит источники, традиции и связанных философов
3. **Количественные характеристики**: Все категории имеют метрики центральности, определенности и исторической значимости
4. **Разные типы связей**: Использованы иерархические, диалектические, функциональные и эпистемологические связи
5. **Взаимосвязанность**: Связи между категориями демонстрируют логическую структуру каждой концепции

## Как использовать этот пример

### 1. Импорт в приложение:
1. Скачайте файл JSON
2. Откройте приложение "Сервис философских концепций"
3. Нажмите кнопку "Импорт базы данных"
4. Выберите скачанный файл

### 2. Изучение концепций:
- Выберите концепцию из списка
- Изучите граф категорий и связей
- Используйте функции анализа для понимания структуры

### 3. Эксперименты:
- Попробуйте генерацию тезисов для каждой концепции
- Синтезируйте новые концепции на основе существующих
- Используйте интеллектуальный анализ для получения рекомендаций

## Рекомендуемые эксперименты

1. **Синтез платонизма и кантианства**
   - Сравните понятия "мир идей" и "вещь в себе"
   - Исследуйте возможности синтеза трансцендентального и объективного идеализма

2. **Анализ диалектических связей**
   - Сравните диалектику Канта и Гегеля
   - Изучите эволюцию понятия диалектики

3. **Генерация тезисов**
   - Сгенерируйте онтологические тезисы для каждой системы
   - Сравните эпистемологические аспекты концепций

4. **Исторический анализ**
   - Используйте функцию "Историческая контекстуализация"
   - Изучите влияние концепций друг на друга

## Расширение примера

Вы можете расширить этот пример, добавляя:
- Новые категории к существующим концепциям
- Дополнительные связи между категориями
- Новые философские концепции (например, материализм, феноменологию, экзистенциализм)
- Современные философские направления

## Примечания

- API ключ в примере пустой - вставьте свой ключ после импорта
- Дата экспорта указана условно
- Все количественные характеристики являются примерными и могут быть скорректированы
