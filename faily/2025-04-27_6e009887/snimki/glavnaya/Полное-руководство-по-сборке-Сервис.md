# Полное руководство по сборке "Сервиса философских концепций"

## Обзор компонентов

Приложение состоит из 7 основных частей:

1. **Часть 1**: HTML структура и базовые CSS стили
2. **Часть 2**: Функции работы с базой данных и API Claude
3. **Часть 3**: Генерация тезисов и синтез концепций
4. **Часть 4**: Дополнительные функции и управление концепциями
5. **Часть 5**: Продвинутая визуализация графа и история изменений
6. **Часть 6**: Расширенный UI и функции экспорта
7. **Часть 7**: Продвинутый анализ и интеллектуальный помощник

## Пошаговая сборка

### Шаг 1: Создание основного файла

1. Создайте файл `philosophical-concepts.html`
2. Скопируйте содержимое из **Части 1** в этот файл

### Шаг 2: Объединение JavaScript кода

Найдите тег `<script>` перед закрывающим `</body>` и добавьте код в следующем порядке:

1. Код из Части 1 (уже в файле)
2. Код из Части 2 (сразу после первого блока)
3. Код из Части 3
4. Код из Части 4
5. Код из Части 5
6. Код из Части 6
7. Код из Части 7

### Шаг 3: Структура готового файла

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Сервис философских концепций</title>
    <style>
        /* Все CSS стили из Части 1 */
        /* Дополнительные стили из других частей будут добавлены динамически */
    </style>
</head>
<body>
    <!-- HTML структура из Части 1 -->
    
    <script>
        // Часть 1: Основные структуры данных
        // Часть 2: Работа с базой данных и API
        // Часть 3: Генерация тезисов и синтез
        // Часть 4: Дополнительные функции
        // Часть 5: Продвинутая визуализация
        // Часть 6: Расширенный UI
        // Часть 7: Продвинутый анализ
    </script>
</body>
</html>
```

### Шаг 4: Проверка функциональности

После сборки проверьте следующие функции:

1. **Базовые функции**:
   - Создание категорий и связей
   - Сохранение и загрузка базы данных
   - Работа с API Claude

2. **Визуализация**:
   - SVG граф с интерактивными узлами
   - Визуализация метрик
   - Анимации

3. **Продвинутые функции**:
   - История изменений (undo/redo)
   - Управление версиями
   - Интеллектуальный анализ

4. **Экспорт**:
   - Экспорт в JSON, CSV, PDF, LaTeX
   - Экспорт отчетов анализа

## Настройка и запуск

### 1. Требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- API ключ от Anthropic Claude
- Активное интернет-соединение

### 2. Первый запуск
1. Откройте файл в браузере
2. Введите API ключ Claude
3. Создайте первую концепцию
4. Начните добавлять категории и связи

### 3. Рекомендации по использованию

**Работа с концепциями**:
- Используйте понятные названия категорий
- Добавляйте подробные описания
- Регулярно сохраняйте версии

**Использование Claude**:
- Валидируйте граф для проверки логики
- Генерируйте тезисы для анализа
- Используйте интеллектуальный анализ для улучшения

**Визуализация и анализ**:
- Изучайте метрики графа
- Используйте рекомендации для улучшения
- Экспортируйте результаты для документации

## Решение проблем

### Частые ошибки

1. **API ключ не работает**:
   - Проверьте правильность ключа
   - Убедитесь, что ключ активен
   - Проверьте интернет-соединение

2. **Граф не отображается**:
   - Убедитесь, что выбрана концепция
   - Проверьте консоль браузера (F12)
   - Обновите страницу

3. **Ошибки при экспорте**:
   - Проверьте наличие данных
   - Убедитесь в правах на сохранение файлов

### Отладка

1. Откройте консоль разработчика (F12)
2. Проверьте наличие ошибок JavaScript
3. Используйте `console.log()` для отладки
