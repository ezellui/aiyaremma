# Решение проблемы с перетаскиванием узлов

## 🐛 Описание проблемы

**Симптомы:**
- После 1-2 перетаскиваний узлов дальнейшие перетаскивания не работают
- В консоли видно, что за один кадр проходят сотни тиков
- Симуляция мгновенно останавливается
- После нажатия "Перезапустить" снова можно сделать 1-2 перетаскивания

## 🔍 Причина проблемы

Проблема была в **управлении счётчиком тиков** (`tickCount`). Вот что происходило:

### Исходный код (с ошибкой):

```javascript
let tickCount = 0;
const MAX_TICKS = 200;

simulation.on("tick", () => {
    const now = performance.now();
    
    // Пропускаем тики, если прошло мало времени
    if (now - lastTickTime < TICK_INTERVAL) {
        return;  // ← НО tickCount НЕ инкрементировался здесь!
    }
    lastTickTime = now;
    tickCount++;  // ← Инкрементируется ПОСЛЕ проверки
    
    // ...обновления...
    
    if (tickCount >= MAX_TICKS || simulation.alpha() < 0.01) {
        simulation.stop();  // ← Остановка по достижению лимита
    }
});

function dragstarted(event, d) {
    if (!event.active) simulation.alphaTarget(0.3).restart();
    // ← tickCount НЕ сбрасывался!
    d.fx = d.x;
    d.fy = d.y;
}
```

### Что происходило пошагово:

1. **Первая загрузка:** 
   - `tickCount = 0`
   - Симуляция запускается, делает ~200 тиков
   - `tickCount = 200`, симуляция останавливается ✓

2. **Первое перетаскивание:**
   - `dragstarted()` вызывает `simulation.restart()`
   - НО `tickCount` всё ещё = 200!
   - Симуляция запускается, делает несколько тиков
   - `tickCount = 203`, сразу останавливается (>= MAX_TICKS)

3. **Второе перетаскивание:**
   - `tickCount = 203`
   - Симуляция мгновенно останавливается
   - Узел не двигается ✗

### Дополнительная проблема:

D3 генерирует tick-события очень быстро (могут быть сотни тиков в секунду). 

Даже если мы пропускаем обновление визуализации из-за `TICK_INTERVAL`, D3 всё равно вызывает обработчик tick. В исходном коде мы делали `return` до инкремента `tickCount`, но это создавало путаницу.

---

## ✅ Решение

Внесены три исправления:

### Исправление 1: Сброс счётчика при перетаскивании

```javascript
function dragstarted(event, d) {
    if (!event.active) {
        tickCount = 0; // ← ДОБАВЛЕНО: Сбрасываем счётчик
        simulation.alphaTarget(0.3).restart();
    }
    d.fx = d.x;
    d.fy = d.y;
}
```

**Эффект:** Каждое перетаскивание начинает с нового отсчёта тиков.

---

### Исправление 2: Остановка только по alpha (не по tickCount)

```javascript
simulation.on("tick", () => {
    // ... обновления ...
    
    // Останавливаем ТОЛЬКО по alpha, не по tickCount
    if (simulation.alpha() < 0.005) {  // ← ИЗМЕНЕНО
        simulation.stop();
        console.log("Симуляция остановлена, alpha < 0.005");
    }
});
```

**Почему так лучше:**
- `alpha` - это естественная метрика энергии системы
- Когда alpha мала, симуляция стабилизировалась
- `tickCount` - искусственное ограничение, которое может сработать преждевременно

**Альтернатива (если нужен лимит):**
```javascript
const MAX_TICKS = 1000; // ← Увеличить лимит

if (tickCount >= MAX_TICKS || simulation.alpha() < 0.005) {
    simulation.stop();
}
```

---

### Исправление 3: Сброс в resetSimulation

```javascript
function resetSimulation() {
    nodes.forEach(n => {
        n.fx = null;
        n.fy = null;
    });
    tickCount = 0;        // ← ДОБАВЛЕНО
    lastTickTime = 0;     // ← ДОБАВЛЕНО
    simulation.alpha(1).restart();
    console.log("Симуляция перезапущена");
}
```

**Эффект:** Кнопка "Перезапустить" полностью сбрасывает состояние.

## 🎓 Урок на будущее

**Общий принцип:** При использовании D3 Force Simulation:

1. **Сбрасывайте состояние** при restart:
   ```javascript
   simulation.on("restart", () => {
       tickCount = 0;
       lastUpdateTime = 0;
   });
   ```

2. **Предпочитайте alpha для остановки:**
   ```javascript
   if (simulation.alpha() < 0.005) {
       simulation.stop();
   }
   ```

3. **Не полагайтесь на tickCount** как на основной механизм остановки - используйте его только как страховку от бесконечного цикла:
   ```javascript
   const EMERGENCY_STOP = 5000; // Аварийная остановка
   if (tickCount > EMERGENCY_STOP) {
       console.warn("Аварийная остановка!");
       simulation.stop();
   }
   ```

---

## 🔧 Если проблема повторяется

Если после применения исправлений проблема всё ещё возникает, проверьте:

1. **В консоли DevTools:** значения `tickCount` и `alpha` при каждом перетаскивании
2. **Ограничения симуляции:** возможно, слишком сильные силы (charge/link)
3. **Количество узлов:** при очень большом графе может быть нужен Canvas
