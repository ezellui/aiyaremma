### Этап 3: Обновление существующих функций (10 минут)

#### 3.1 Добавить автосохранение
В каждую функцию сохранения/удаления добавить **перед** `closeEdit...Modal()`:
```javascript
autoSave();
```

**Функции для модификации:**
- `savePhilosopher()`
- `saveConcept()`
- `saveConnection()`
- `deletePhilosopher()`
- `deleteConcept()`
- `deleteConnection()`

#### 3.2 Обновить инициализацию графа
**Найти код:**
```javascript
console.log("Инициализация графа:", nodes.length, "узлов,", links.length, "связей");
initFilters();
updateFilterStats();
```

**Заменить на:**
```javascript
function initializeApp() {
    console.log("🎨 Инициализация графа:", nodes.length, "узлов,", links.length, "связей");
    
    // Создаем SVG и запускаем симуляцию
    // (весь существующий код инициализации графа перенести сюда)
    
    initFilters();
    updateFilterStats();
    setTimeout(makeLegendsEditable, 100);
    
    console.log("✅ Приложение готово к работе");
}
```

#### 3.3 Обновить функцию initFilters()
**В конце функции добавить:**
```javascript
makeLegendsEditable();
```

#### 3.4 Обновить обработчик кликов на связях
**Найти:** `.on("click", ...)` для связей (примерно строка 1600)

**Заменить на:**
```javascript
.on("click", function(event, d) {
    if (event.shiftKey) {
        event.stopPropagation();
        openEditConnectionModal(d.source.id || d.source, d.target.id || d.target);
    } else {
        handleLinkClick(event, d);
    }
})
```

## 🔧 Устранение проблем

### Проблема: Данные не загружаются
**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что путь к JSON правильный: `./data/philosophy_data.json`
3. Проверьте, что JSON файл валидный (используйте JSONLint)

### Проблема: Изменения не сохраняются
**Решение:**
1. Проверьте, что автосохранение включено (панель управления)
2. Проверьте консоль: должно быть сообщение `💾 Данные сохранены в LocalStorage`
3. Проверьте, что `autoSave()` вызывается в функциях сохранения

### Проблема: Граф не отображается
**Решение:**
1. Проверьте, что функция `initializeApp()` вызывается
2. Проверьте, что все данные загрузились корректно
3. Проверьте консоль на JavaScript ошибки

### Проблема: Shift+Click не работает
**Решение:**
1. Проверьте, что обработчики событий добавлены
2. Проверьте, что функция `makeLegendsEditable()` вызывается
3. Попробуйте перезагрузить страницу

## 💡 Полезные советы

### Резервное копирование
Регулярно экспортируйте данные через панель управления:
1. Открыть панель управления
2. Нажать "📤 Экспортировать в JSON"
3. Сохранить файл с датой, например: `backup_2024-01-15.json`

### Работа в команде
Для совместной работы:
1. Один человек редактирует граф
2. Экспортирует данные в JSON
3. Передаёт файл другим
4. Другие импортируют через панель управления

### Сброс к исходному состоянию
Если что-то пошло не так:
1. Панель управления → "Сбросить к исходным данным"
2. Данные из `philosophy_data.json` перезагрузятся
