# 📚 Интерактивный редактор графа философских концепций

## 🎯 Обзор проекта

Это комплексное решение для добавления функционала интерактивного редактирования в граф философских концепций. Проект включает:

- ✏️ **Редактирование философов, концепций и связей**
- 💾 **Автоматическое сохранение данных в LocalStorage**
- 📁 **Экспорт/импорт данных в JSON**
- 🔄 **Обновление графа без перезагрузки страницы**
- ⚙️ **Панель управления данными**

---

## 🎮 Управление после интеграции

### Горячие клавиши

| Действие | Комбинация |
|----------|-----------|
| Добавить философа | `Shift` + Click на пустом месте блока философов |
| Редактировать философа | `Shift` + Click на философе |
| Добавить концепцию | `Shift` + Click на пустом месте графа |
| Редактировать концепцию | `Shift` + Click на концепции |
| Создать связь | `Shift` + Click на первой концепции, затем на второй |
| Редактировать связь | `Shift` + Click на связи |
| Закрыть окно | `ESC` |

### Панель управления данными

**Расположение:** Кнопка внизу слева экрана

**Функции:**
- 📊 Просмотр статистики
- 💾 Ручное сохранение
- 📤 Экспорт в JSON
- 📥 Импорт из JSON
- 🔄 Сброс к исходным данным
- ⚠️ Очистка всех данных

- Максимальный размер: ~5-10 МБ (зависит от браузера)

1. Регулярно экспортируйте данные в JSON
2. Храните резервные копии

### Совместная работа

1. Один человек редактирует и экспортирует данные
2. Передаёт JSON файл другим

## ❓ FAQ

**Q: Нужен ли сервер для работы?**  
A: Нет, всё работает локально в браузере. Сервер нужен только если вы хотите хранить данные централизованно.

**Q: Где хранятся данные?**  
A: В LocalStorage вашего браузера. Также можно экспортировать в JSON файл.

**Q: Что если я закрою браузер?**  
A: Все изменения сохранятся в LocalStorage и будут доступны при следующем открытии.

**Q: Можно ли откатить изменения?**  
A: Да, через панель управления → "Сбросить к исходным данным".

**Q: Как перенести данные на другой компьютер?**  
A: Экспортируйте данные в JSON, скопируйте файл, импортируйте на другом компьютере.

**Q: Работает ли оффлайн?**  
A: Да, после первой загрузки страница работает полностью оффлайн.

## 🐛 Устранение проблем

### Проблема: Данные не загружаются
```
1. Откройте консоль (F12)
2. Проверьте путь к JSON: ./data/philosophy_data.json
3. Убедитесь, что JSON валидный
4. Проверьте CORS политику (файл должен быть на том же домене)
```

### Проблема: Изменения не сохраняются
```
1. Проверьте, что автосохранение включено
2. Проверьте консоль на ошибки
3. Убедитесь, что LocalStorage не заблокирован
4. Попробуйте ручное сохранение
```

### Проблема: Shift+Click не работает
```
1. Проверьте, что функция makeLegendsEditable() вызывается
2. Убедитесь, что обработчики событий добавлены
3. Перезагрузите страницу
4. Попробуйте в другом браузере
```
