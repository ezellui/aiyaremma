
# Схема взаимодействия с Claude для философского сервиса

## Уровень 1: Составление графа концепции

### Интерфейс пользователя
- **Панель категорий**: Пользователь создает и именует философские категории
- **Панель связей**: Пользователь определяет типы связей (противоречие, следование, включение и т.д.)
- **Рабочая область**: Визуальное представление графа с возможностью drag-and-drop размещения элементов
- **Панель структурных атрибутов**: Вместо числовых весов — качественные атрибуты:
  - Структурная роль: фундаментальное/производное понятие
  - Функция: аксиома/следствие/постулат
  - Онтологический статус понятия в системе

### Взаимодействие с Claude
1. **Помощь в формулировании категорий**:
   ```
   Запрос: "Я работаю над концепцией свободы воли в детерминистическом мире. Какие ключевые категории я должен включить?"
   Ответ Claude: [предложения по категориям с обоснованием их необходимости]
   ```

2. **Валидация связей**:
   ```
   Запрос: "Я соединил 'моральную ответственность' и 'детерминизм' связью типа 'включение'. Корректно ли это с философской точки зрения?"
   Ответ Claude: [анализ корректности связи, возможные альтернативы]
   ```

3. **Анализ структурной целостности графа**:
   ```
   Запрос: "Проанализируй мой граф на наличие логических противоречий и структурных пробелов"
   Ответ Claude: [выявление противоречий, предложения по улучшению структуры]
   ```

### Данные для Claude
- Полная структура графа (узлы и связи)
- Описательные атрибуты категорий и связей
- Область философии/контекст концепции
- Исторические основания (если имеются)

## Уровень 2: Генерация тезисов на основе графа

### Интерфейс пользователя
- **Параметры генерации**: настройки глубины, формальности, стиля изложения
- **Панель исторических отсылок**: возможность указать желаемые отсылки к существующим философским традициям
- **Панель фокусировки**: выделение узлов графа, которые должны стать центральными в тезисах

### Взаимодействие с Claude
1. **Первичная генерация тезисов**:
   ```
   Запрос: [Структура графа + параметры генерации]
   Ответ Claude: [Набор взаимосвязанных тезисов, отражающих структуру графа]
   ```

2. **Уточнение и развитие тезисов**:
   ```
   Запрос: "Развей тезис #3 о соотношении свободы и необходимости"
   Ответ Claude: [Развернутое изложение тезиса с аргументацией]
   ```

3. **Обнаружение следствий**:
   ```
   Запрос: "Какие философские следствия вытекают из этой системы тезисов?"
   Ответ Claude: [Анализ неявных следствий из представленных тезисов]
   ```

### Данные для Claude
- Полная структура графа
- Структурные атрибуты элементов
- Параметры генерации
- История предыдущих итераций (для последовательного улучшения)

### Пример промпта для Claude
```
Сгенерируй философские тезисы на основе следующего категориального графа:

Категории:
1. Сознание [фундаментальное понятие]
2. Материя [фундаментальное понятие]
3. Причинность [производное понятие]
4. Свобода воли [производное понятие]

Связи:
- Сознание — противоречие — Материя
- Материя — следование — Причинность
- Причинность — ограничение — Свобода воли
- Сознание — обоснование — Свобода воли

Стиль: аналитический
Фокус: взаимосвязь сознания и свободы
Историческая традиция: постдуализм
```

## Уровень 3: Синтезирование новых концепций

### Интерфейс пользователя
- **Панель выбора концепций**: возможность выбрать 2+ концепции для синтеза
- **Параметры синтеза**: способы разрешения противоречий, преобладающая парадигма
- **Настройки сохранения элементов**: какие элементы исходных концепций должны быть сохранены
- **Визуализация синтеза**: предварительное отображение структуры синтезированной концепции

### Взаимодействия с Claude
1. **Анализ совместимости**:
   ```
   Запрос: "Проанализируй совместимость концепций A и B для синтеза"
   Ответ Claude: [Анализ общих оснований, противоречий, возможностей интеграции]
   ```

2. **Генерация синтетического графа**:
   ```
   Запрос: [Структуры исходных графов + параметры синтеза]
   Ответ Claude: [Структура нового графа с обоснованием трансформаций]
   ```

3. **Разработка синтетических тезисов**:
   ```
   Запрос: "Сформулируй тезисы синтезированной концепции"
   Ответ Claude: [Набор тезисов с объяснением их происхождения из исходных концепций]
   ```

4. **Рефлексия о синтезе**:
   ```
   Запрос: "Проведи метаанализ проведенного синтеза"
   Ответ Claude: [Философское обоснование методологии синтеза, анализ потенциальных проблем]
   ```

### Данные для Claude
- Структуры исходных графов
- Тезисы исходных концепций
- Параметры синтеза и разрешения противоречий
- Методологические предпочтения пользователя

### Стратегии синтеза (для Claude)
1. **Диалектический синтез**: поиск и разрешение противоречий между концепциями
2. **Иерархический синтез**: включение одной концепции в качестве подсистемы другой
3. **Дополнительностный синтез**: сохранение несоизмеримых аспектов как дополнительных перспектив
4. **Интегративный синтез**: создание метатеоретической структуры, объединяющей исходные концепции

### Пример промпта для синтеза
```
Синтезируй две философские концепции:

Концепция 1: [граф концепции трансцендентального идеализма]
Тезисы концепции 1: [список тезисов]

Концепция 2: [граф концепции феноменологии]
Тезисы концепции 2: [список тезисов]

Параметры синтеза:
- Стратегия: диалектический синтез
- Сохранить основные положения о структуре сознания из концепции 2
- Преобладающая парадигма: концепция 1
- Разрешение противоречий: через трансформацию категорий

Представь результат в виде:
1. Нового категориального графа
2. Основных тезисов синтезированной концепции
3. Методологического комментария о проведенном синтезе
```

## Примеры полных сценариев взаимодействия

### Сценарий 1: Разработка новой концепции с нуля
1. Пользователь начинает с пустого графа и формулирует основные категории
2. Пользователь запрашивает у Claude предложения по дополнительным категориям
3. Пользователь строит связи между категориями
4. Пользователь запрашивает проверку логической целостности
5. Claude анализирует граф и предлагает структурные улучшения
6. Пользователь корректирует граф согласно рекомендациям
7. Пользователь запрашивает генерацию тезисов
8. Claude генерирует набор взаимосвязанных тезисов
9. Пользователь запрашивает развитие отдельных тезисов
10. Claude предлагает возможные следствия из концепции

### Сценарий 2: Синтез существующих концепций
1. Пользователь выбирает две существующие концепции для синтеза
2. Пользователь запрашивает анализ совместимости
3. Claude выявляет общие основания и принципиальные противоречия
4. Пользователь выбирает параметры синтеза, указывая разрешение противоречий
5. Claude предлагает структуру синтезированного графа
6. Пользователь корректирует предложенный граф
7. Пользователь запрашивает тезисы на основе синтезированного графа
8. Claude генерирует тезисы с пояснением происхождения из исходных концепций
9. Пользователь запрашивает рефлексию о методологии синтеза
10. Claude предоставляет метаанализ проведенного синтеза
