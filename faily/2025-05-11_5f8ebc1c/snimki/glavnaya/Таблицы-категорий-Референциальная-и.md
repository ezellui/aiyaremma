## ПРАВИЛА КОМБИНИРОВАНИЯ

### Порядок аффиксов в референциальной матрице:
```
[Определ.префикс] + [Инклюз.инфикс] + КОРЕНЬ + [Колич.суффикс] + [Извест.постфикс] + [Дейксис частица] + [Видим.клитика]
```

### Порядок аффиксов в прагматической матрице:
```
[Иллокут.префикс] + [Соц.дист.инфикс] + КОРЕНЬ + [Вежлив.суффикс] + [Регистр циркумфикс]
```

### Типичные комбинации референциальных категорий:

| Комбинация | Референциальный тип | Пример |
|------------|--------------------:|---------|
| Конкретный + Единичный + Проксимальный + Видимый | Непосредственный объект | def-sing=prox+vis |
| Генерический + Множественный + Неизвестный | Общее утверждение | gen-plur-unknow |
| Абстрактный + Собирательный + Известный всем | Культурный концепт | abstr-coll-uknow |

### Типичные комбинации прагматических категорий:

| Комбинация | Коммуникативная ситуация | Пример |
|------------|-------------------------|---------|
| Приказ + Формальная + Уважительная | Официальное распоряжение | imper-form-resp |
| Просьба + Интимная + Фамильярная | Дружеская просьба | req-intim-fam |
| Утверждение + Нейтральная + Научный | Академическое высказывание | assert-neutr-acad-...-ic |

### Примеры полных форм:

1. **def-spk+-sing-mknow=prox+vis**
   - "конкретный единичный референт, включающий говорящего, известный участникам, близкий и видимый"

2. **gen-addr--plur-uknow=dist+nvis**
   - "генерический множественный референт, исключающий адресата, известный всем, далёкий и невидимый"

3. **assert-form-resp-acad-...-ic**
   - "утверждение в формальной дистанции с уважением в академическом регистре"

4. **req-close-fam-coll-...-ial**
   - "просьба в близких отношениях фамильярно в разговорном регистре"
