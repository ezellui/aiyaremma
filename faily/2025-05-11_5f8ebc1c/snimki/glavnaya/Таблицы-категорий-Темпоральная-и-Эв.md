## ПРАВИЛА КОМБИНИРОВАНИЯ ТЕМПОРАЛЬНЫХ И ЭВИДЕНЦИАЛЬНЫХ КАТЕГОРИЙ

### Порядок аффиксов в темпоральной матрице:
```
[Префикс врем.] + [Инфикс отн.врем.] + КОРЕНЬ + [Суффикс аспект.] + [Циркумфикс мод.] + [Частица дист.] + [Клитика опред.]
```

### Порядок аффиксов в эвиденциальной матрице:
```
[Префикс источн.] + [Инфикс модус] + КОРЕНЬ + [Суффикс достов.] + [Частица врем.дист.]
```

### Совместное использование:
```
[Врем.префикс] + [Эвид.префикс] + [Отн.врем.] + [Модус] + КОРЕНЬ + [Аспект] + [Достов.] + [Модальн.] + [Дист.] + [Опред.]
```

### Примеры полных форм:

1. **ta-wit-pri-vis-READ-dur-abs-prox=prec**
   - "читал (до другого события, свидетельствовал визуально с абсолютной уверенностью, близкое прошлое, точно)"

2. **fu-inf-sim-HAPPEN-inch-med-pot-temp-dist=approx**
   - "возможно начнёт происходить (одновременно с другим, вывод со средней уверенностью, далёкое будущее, приблизительно)"

3. **æ-com-EXIST-hab-hic=indef**
   - "существует всегда (общее знание, привычно, высокая уверенность, время неопределённо)"
