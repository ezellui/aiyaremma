## ПРАВИЛА КОМБИНИРОВАНИЯ

### Порядок аффиксов в аспектуально-акциональной матрице:
```
[Времен.структ.префикс] + [Фазов.инфикс] + КОРЕНЬ + [Кратн.суффикс] + [Телич.постфикс] + [Интенс.клитика]
```

### Порядок аффиксов в каузативной матрице:
```
[Тип кауз.префикс] + [Намерен.инфикс] + КОРЕНЬ + [Принужд.суффикс] + [Успеш.постфикс]
```

### Акциональные классы и их типичные комбинации:

| Акциональный класс | Типичная комбинация | Пример |
|-------------------|--------------------:|---------|
| States (состояния) | Статичность + Непредельность | stat-atel |
| Activities (деятельности) | Процессуальность + Непредельность | proc-atel |
| Accomplishments (свершения) | Процессуальность + Предельность | proc-tel |
| Achievements (достижения) | Точечность + Предельность | punct-tel |
| Semelfactives (семельфактивы) | Точечность + Однократность | punct-semel |

### Каузативные ситуации и их типичные реализации:

| Тип ситуации | Типичная комбинация | Пример |
|-------------|--------------------:|---------|
| Приказание | Прямая + Абсолютное + Целенаправленная | dir-intent-abscoer |
| Позволение | Пермиссивная + Минимальное + Целенаправленная | perm-intent-mincoer |
| Помощь | Ассистивная + Слабое + Целенаправленная | assist-intent-weakcoer |
| Случайное воздействие | Косвенная + Слабое + Случайная | indir-accid-weakcoer |

### Примеры полных форм:

1. **proc-prog-freq-atel=high**
   - "процессуальное действие в прогрессивной фазе, регулярно повторяющееся, непредельное, высокой интенсивности"

2. **punct-inch-semel-tel=max**
   - "точечное действие в начальной фазе, однократное, предельное, максимальной интенсивности"

3. **dir-intent-strcoer-fullsucc**
   - "прямая каузация, целенаправленная, с сильным принуждением, полностью успешная"

4. **assist-accid-weakcoer-partsucc**
   - "ассистивная каузация, случайная, со слабым принуждением, частично успешная"

### Взаимодействие аспектуальных и каузативных категорий:

| Комбинация | Семантический эффект | Пример |
|------------|---------------------|---------|
| Инхоативность + Каузация | Начинать заставлять | -inch- + dir- |
| Результативность + Успешная каузация | Успешно довести до результата | -result- + -fullsucc |
| Регулярность + Ассистивная каузация | Регулярно помогать | -freq + assist- |
