## ПРАВИЛА ВЗАИМОДЕЙСТВИЯ КАТЕГОРИЙ

### 1. Иерархия доминирования:
1. Иллокутивная сила > все остальные категории
2. Темпоральность > Аспектуальность
3. Эвиденциальность > Модальность
4. Актантность > Референциальность
5. Прагматика > Семантика

### 2. Обязательные согласования:
- Темпоральные категории согласуются между собой
- Эвиденциальность согласуется с модальностью
- Актантная структура согласуется с каузативностью
- Референциальность согласуется с количественностью
- Информационная структура согласуется с порядком слов

### 3. Семантические ограничения:

| Несовместимые комбинации | Причина |
|--------------------------|---------|
| Точечность + Прогрессивность | Точечные события не имеют срединной фазы |
| Статичность + Динамические категории | Состояния не меняются |
| Абстрактный референт + Видимость | Абстракции невидимы |
| Сновидение + Тактильный модус | Во сне нет осязания |
| Вневременное + Временная дистанция | Вневременное не имеет дистанции |

### 4. Прагматические фильтры:

| Маловероятные комбинации | Прагматическая причина |
|-------------------------|------------------------|
| Приказ + Почтительность | Приказы обычно не почтительны |
| Угроза + Эмпатия | Угрозы исключают эмпатию |
| Вульгарный регистр + Научная точность | Регистры несовместимы |
| Интимная дистанция + Формальная вежливость | Противоречие социальных норм |
