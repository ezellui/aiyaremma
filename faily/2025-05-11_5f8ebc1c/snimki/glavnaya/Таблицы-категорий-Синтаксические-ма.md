# Таблицы грамматических категорий: Часть 6

## 11. ИНФОРМАЦИОННАЯ СТРУКТУРА (10 измерений)

### 11.1. Топик-фокус (3 значения)

| Значение | Код | Маркер | Описание | Информационная роль |
|----------|-----|---------|----------|-------------------|
| Тематическая часть | TOPIC | top- | О чём говорится | Исходная точка |
| Рематическая часть | FOCUS | foc- | Что говорится | Новая информация |
| Контрастивный фокус | CONTRASTIVE-FOCUS | cfoc- | Выделение через противопоставление | Коррекция/выбор |

| Полностью новая | BRAND-NEW | -bnew | Впервые вводимая | Неактивированная |

### 11.3. Степень активации (3 значения)

| Значение | Код | Маркер | Описание | Когнитивная доступность |

| Активная | ACTIVE | -act- | В центре внимания | Высокая |

| Неактивная | INACTIVE | -inact- | Вне фокуса внимания | Низкая |

| Значение | Код | Маркер | Описание | Прагматический эффект |

## ПРАВИЛА КОМБИНИРОВАНИЯ СИНТАКСИЧЕСКИХ КАТЕГОРИЙ

### Порядок маркеров в информационной структуре:
```
[Топик/фокус префикс] + [Активация инфикс] + ЭЛЕМЕНТ + [Данное/новое суффикс] + [Перспектива клитика]
```

### Порядок маркеров в синтаксической связности:
```
[Тип связи префикс] + [Иерархия инфикс] + КЛАУЗА + [Интеграция суффикс] + [Порядок циркумфикс]
```

### Порядок маркеров в дискурсивной когерентности:
```
[Тип отношений префикс] + [Эксплицитность инфикс] + ЭЛЕМЕНТ + [Анафора суффикс] + [Дискурс.маркер постфикс]
```

### Типичные информационные конфигурации:

| Структура | Комбинация | Пример |
|-----------|------------|---------|
| Тема-рематическая | Топик + Данное + Активное | top-act-giv |
| Презентационная | Фокус + Новое + Неактивное | foc-inact-bnew |
| Контрастивная | Контрастивный фокус + Частично новое | cfoc-pnew |

### Типичные синтаксические конструкции:

| Конструкция | Комбинация | Пример |
|-------------|------------|---------|
| Сложноподчинённое | Субординация + Главная/Зависимая + Частичная интеграция | subord-main-/-dep-partint |
| Сложносочинённое | Координация + Слабая интеграция | coord-weakint |
| Коррелятивная | Корреляция + Полная интеграция | correl-fullint |

### Типичные дискурсивные связи:

| Отношение | Комбинация | Пример |
|-----------|------------|---------|
| Причинное объяснение | Причинно-следственное + Явное + Аддитивное | caus-expl-add |
| Контраст | Уступительное + Имплицитное + Контрастивное | conc-impl-contr |
| Обобщение | Резюмирующее + Явное | summ-expl- |

### Примеры полных форм:

1. **top-act-giv=neutp**
   - "топик, активный, данная информация, нейтральная перспектива"

2. **foc-semi-pnew=emphp**
   - "фокус, полуактивный, частично новая информация, эмфатическая перспектива"

3. **subord-dep-partint-post-...-pos**
   - "субординация, зависимая клауза, частичная интеграция, постпозиция"

4. **caus-expl-pron-add**
   - "причинно-следственное отношение, явная связь, местоименная анафора, аддитивный маркер"
