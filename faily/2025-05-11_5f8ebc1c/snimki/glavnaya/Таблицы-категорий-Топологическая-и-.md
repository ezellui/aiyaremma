## ПРАВИЛА КОМБИНИРОВАНИЯ

### Порядок аффиксов в топологической матрице:
```
[Простр.конфиг.префикс] + [Направл.инфикс] + КОРЕНЬ + [Ориент.суффикс] + [Динам.циркумфикс]
```

### Порядок аффиксов в эмотивно-оценочной матрице:
```
[Эмоц.префикс] + [Отнош.инфикс] + КОРЕНЬ + [Интенс.суффикс] + [Аксиол.постфикс] + [Вовлеч.клитика]
```

### Типичные топологические конфигурации:

| Ситуация | Комбинация | Пример |
|----------|------------|---------|
| Объект в контейнере | Включение + Статичная | contain-stat-...-ic |
| Движение к цели | Близость + Центростремительное + Движущаяся | prox-centr-in-mov-...-ing |
| Круговое движение | Циркулярное + Горизонтальная + Движущаяся | -circ-horiz-mov-...-ing |
| Падение | Вертикальная + Ускоряющаяся | -vert-acc-...-ing |

### Типичные эмоционально-оценочные комплексы:

| Эмоциональное состояние | Комбинация | Пример |
|------------------------|------------|---------|
| Восхищение | Радость + Одобрение + Положительная + Сильная | joy-appr-emstr-posval |
| Презрение | Отвращение + Неодобрение + Отрицательная | disg-disappr-negval |
| Сострадание | Грусть + Эмпатия + Личная | sad-emp-=pers |
| Скептицизм | Удивление + Ирония + Амбивалентная | surp-iron-ambival |

### Примеры полных форм:

1. **cont-trans-horiz-mov-...-ing**
   - "в контакте, движется транзитивно в горизонтальной ориентации"

2. **contain-centr-in-vert-stat-...-ic**
   - "включён внутрь, центростремительно, вертикально, статично"

3. **joy-appr-emstr-posval=pers**
   - "радость с одобрением, сильной интенсивности, положительная оценка, личная вовлечённость"

4. **fear-emp-emmod-neutval=det**
   - "страх с эмпатией, умеренной интенсивности, нейтральная оценка, отстранённая позиция"

### Метафорические расширения топологических категорий:

| Физическое | Метафорическое | Пример |
|------------|----------------|---------|
| Включение | Принадлежность к группе | "включён в коллектив" |
| Вертикальность | Иерархия | "выше по статусу" |
| Близость | Эмоциональная близость | "близкие отношения" |
| Центростремительность | Фокусировка внимания | "сосредоточиться на проблеме" |
