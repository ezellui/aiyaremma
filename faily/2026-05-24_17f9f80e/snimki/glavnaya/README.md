# «Изоморфизмы» — журнальная вёрстка в LaTeX

Этот комплект превращает единый HTML-выпуск в файл `.tex` с вёрсткой научного
журнала. Преобразование выполняет **скрипт** `convert.py` (а не ручная правка),
поэтому при изменении HTML достаточно перегенерировать `.tex`.

## Состав

| файл | назначение |
|------|------------|
| `convert.py` | конвертер HTML → XeLaTeX (BeautifulSoup) |
| `izomorfizmy-vypusk-polnyj.html` | исходный единый выпуск |
| `izomorfizmy.tex` | сгенерированный LaTeX-файл |
| `izomorfizmy.pdf` | скомпилированный результат (46 страниц) |
| `fonts/` | 11 файлов шрифтов (Old Standard TT, Spectral) |
| `Makefile` | сборка одной командой |

## Сборка

Нужен **XeLaTeX** (TeX Live / MiKTeX). Шрифты подключаются прямо из папки
`fonts/` через `fontspec` — устанавливать их в систему не требуется.

```sh
make            # convert.py -> izomorfizmy.tex -> xelatex x2 -> izomorfizmy.pdf
# либо вручную:
python3 convert.py izomorfizmy-vypusk-polnyj.html izomorfizmy.tex
xelatex izomorfizmy.tex
xelatex izomorfizmy.tex
```

## Шрифты

* **Old Standard TT** (`\displayfont`) — заголовки, номера разделов, буквицы, рубрики;
  начертания Regular / Italic / Bold (Bold Italic синтезируется наклоном).
* **Spectral** (`\setmainfont` и `\lightfont`) — основной текст;
  Regular / Italic / SemiBold(=bold) / SemiBold Italic, а также Light / Light Italic
  для подзаголовков.

Файлы взяты из репозитория Google Fonts (лицензия OFL) и встраиваются в PDF.

## Что переносится

Всё содержимое: обложка, предисловие, содержание, пять статей (со всеми
разделами, аннотациями, формулами, пулл-цитатами, буквицами, примечаниями и
библиографиями), послесловие. Веб-навигация (верхняя панель, пейджеры, кнопки)
отбрасывается — это не текст. Акцентный цвет каждой статьи сохранён
(Деррида — оксфорд-красный, Лейбниц — синий, Гегель — фиолетовый,
Ницше — сиенна, Левинас — бирюза; обрамление — золото).

## Замечание о переносах

В использованном дистрибутиве не оказалось образцов переноса для русского
(`loadhyph-ru.tex`), а XeTeX не умеет подгружать их во время выполнения.
Чтобы строки не выходили на поля, в преамбуле включено растяжение межсловных
пробелов (`\tolerance`, `\emergencystretch`). Если в вашем TeX Live русские
переносы установлены, можно убрать эти строки — вёрстка станет ещё плотнее.
Движок LuaLaTeX (умеющий подгружать переносы на лету) также подойдёт, если в
системе есть его вспомогательные пакеты.
