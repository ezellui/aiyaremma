# ПЛАН ВСЕСТОРОННЕЙ ПРОРАБОТКИ ПРОЕКТА

## «Синэстематика эмотивной лингволоники»

Настоящий план — дорожная карта доведения файла `02-skeleton.html` до законченного состояния, описанного в дизайн-документе. План разбит на три сквозные оси (визуальная / концептуальная / функциональная) и десять фаз работы. В конце приведена единая сводная таблица приоритетов и распределение по запросам к Claude.

---

## 0. Вводные замечания

- Работа ведётся **итеративно**: в каждом запросе Claude получает скелет + текущее состояние файла и доводит ограниченный набор пунктов плана.
- Приоритет **P0** — критичные узлы, без которых остальное теряет смысл (данные-якоря, ядро вычислений, переключатель модулей).
- Приоритет **P1** — основные модули, формирующие базовый опыт.
- Приоритет **P2** — вторичные модули и украшающие подсистемы.
- Приоритет **P3** — полировка, пасхалки, микроанимации, звуковой слой.
- План ориентирован на **семь запросов**. Каждому запросу соответствует выделенный пакет пунктов.

## 1. Фаза «Концептуальный каркас» (уже завершена в дизайн-документе)

Все концептуальные основания (онтологическая триада, параметры лингволона, эмотивная роза, модальности, глоссарий базовых терминов) фиксированы в `01-design-document.md`. На этапе реализации они переводятся в данные и стили.

## 2. Фаза «Типографика и визуальные токены»

### 2.1. Подключение шрифтов

- Cormorant Garamond / Old Standard TT — заголовки
- Spectral — основной текст
- JetBrains Mono — моноширинный
- UnifrakturMaguntia — для редких декоративных вставок

### 2.2. Цветовая палитра

- Все девять токенов CSS custom properties, указанных в дизайн-документе
- Восемь векторов эмотивной розы — по цвету на каждый
- Градиенты и маски для «пергаментного» эффекта

### 2.3. Фоновые текстуры

- SVG-шум, слабый градиент виньетки
- Редкие «кляксы» и «пятна от чайных чашек»
- Пальцевые полутени в углах (имитация касания страницы)

### 2.4. Общий ритм заголовков

- H1 — разрядка 0,08em, малые прописные
- H2/H3 — разрядка 0,04em, чистый serif
- Подписи — капителями

## 3. Фаза «Глобальная оболочка»

### 3.1. Шапка кафедры

- Геральдический знак слева (SVG, восьмилучевая роза с сургучным ядром)
- Название кафедры по центру
- Горизонтальное меню модулей справа

### 3.2. Боковой пульт

- Часы с маятником (SVG + CSS-анимация)
- Миниатюрная эмотивная роза, указывающая на вектор текущего лингволона
- Переключатель звука
- Подсказка курсора

### 3.3. Нижняя лента «внимания»

- Хлебные крошки
- Текущий наблюдаемый параметр
- Ротация микротекста (девизы, сноски, номера зала)

### 3.4. Логика переключения модулей

- Функция `switchModule(id)` со сменой классов и плавным переходом
- Клавиатурная навигация по модулям (Tab / стрелки)

### 3.5. Экран-преамбула (заставка)

- Центрированный геральдический знак
- Медленный разворот лепестков розы при загрузке
- Кнопка «Войти» с сургучным оттиском
- После клика — фейд и открытие основной оболочки

## 4. Фаза «Ядро данных»

### 4.1. Лексические якоря

- Ручная разметка ~200 базовых русских лингволонов с параметрами (ν, A, φ, P, Q, K) и шестью модальностями
- Заполнение массива `LINGUOLON_ANCHORS`

### 4.2. 64 эмотивных элемента

- Символы (двубуквенные кириллические сокращения)
- Названия, плотность, вектор, диапазон
- Лабораторные описания (3–5 строк на элемент)

### 4.3. Архив экспонатов

- 16 начальных экспонатов
- Каждый содержит: слово, этимологию, три-четыре псевдоцитаты информантов, SVG-иллюстрацию, замечание кафедры

### 4.4. Глоссарий

- 60–80 терминов, каждый с определением и перекрёстными ссылками

### 4.5. Хроника

- 9 датовых событий
- 5 биографических медальонов
- 12 библиографических записей

---

## 5. Фаза «Ядро вычислений»

### 5.1. Хеш-функция слова

- Детерминированный алгоритм, учитывающий длину, состав, позицию
- Отдельная ветвь для якорных слов — использование готовых значений

### 5.2. Функция `computeLinguolon(word)`

- Возвращает шестёрку параметров
- Якорные слова — из таблицы; остальные — расчётные

### 5.3. Функция `projectToModalities(linguolon)`

- Шесть проекций: цвет, форма, вкус, запах, фактура, температура
- Каждая — отдельная детерминированная функция от параметров

### 5.4. Генератор поэтической реплики

- 8–10 шаблонов, каждый с 4–6 слотами
- Слоты заполняются синонимами/вариантами в зависимости от параметров

### 5.5. Функция интерференции

- Даёт результирующую волну и текстовое описание (усиление / гашение / биения)

### 5.6. Функция кардиограммы

- Для связного текста — массив точек (ν, A, цвет) по позициям
- Сводная эмотивная роза по всему тексту

## 6. Фаза «Модули» — детальная реализация

### 6.1. Лингволоноскоп

- Оформление «приборного стола»
- SVG-роза результатов с шестью анимированными лучами
- Паспорт лингволона в виде документа 1950-х
- Кнопки действий (резонанс, спектрограф, эмотека, архив)

### 6.2. Таблица эмотивных элементов

- Сетка 8×8 клеток, генерируемая из данных
- Hover-состояние: мягкое свечение
- Клик: раскрытие лабораторной карточки
- Поиск и фильтр

### 6.3. Архив сновидческой лексики

- Картотечная вертушка (CSS grid с поворотом)
- Карточка экспоната в развёрнутом виде
- Добавление пользовательских экспонатов
- Поиск и фильтры

### 6.4. Резонансная камера

- Canvas-визуализация интерференции
- Обработка параметров (фаза, дистанция, угол)
- Стрелочный прибор коэффициента когерентности
- Аудиоотклик

### 6.5. Эмотивный спектрограф

- Машинописное поле ввода
- Canvas-волна с градиентной окраской
- Сводка по всему тексту + малая эмотивная роза
- Экспорт кардиограммы в SVG

### 6.6. Атлас синэстем

- Стена галереи с 12 рамами
- Генеративный SVG-отпечаток для каждого лингволона
- Раскрытие отпечатка с описанием
- Добавление своего лингволона

### 6.7. Глоссарий

- Левая колонка алфавита
- Центральный список терминов
- Правая колонка выделенного термина
- Режим случайного показа

### 6.8. Хроника кафедры

- Вступительная статья
- Горизонтальная временная лента
- Пять медальонов учёных
- Библиографический список
- Раздел «Настоящее положение»

### 6.9. Пневматическая эмотека

- Стеллаж из SVG-склянок
- Раскрытие склянки
- Экспорт/импорт JSON
- Очистка

## 7. Фаза «Анимации и микровзаимодействия»

### 7.1. «Дыхание» интерфейса

- Фоновая пульсация ~0,1–0,2 Гц
- Мерцание свечений на ключевых элементах
- Лёгкое смещение тени курсора

### 7.2. Хроматическая аберрация

- Применяется к именам выделенных лингволонов
- Кратковременно включается при проекции

### 7.3. Глитч-эффекты

- Редкие, точечные, при переключении модулей
- Никогда не включаются в центральной области чтения

### 7.4. Кастомные курсоры

- Лингволоноскоп — перо
- Таблица — пипетка
- Архив — маятник
- Резонансная камера — камертон
- Спектрограф — игла
- Атлас — кисть
- Глоссарий — указка
- Хроника — лорнет
- Эмотека — пинцет

### 7.5. Переходы модулей

- Плавный fade + лёгкий сдвиг
- Ненавязчивый звук перелистывания

---

## 8. Фаза «Звуковой слой»

### 8.1. Фоновое дыхание тишины

- Два розовых шума со сдвигом 0,3 Гц
- Очень тихое наложение

### 8.2. Тикание маятника

- Короткий деревянный щелчок раз в секунду
- Чуть слышный, в правом канале

### 8.3. Чистый тон лингволона

- Синусоида с частотой, пропорциональной ν
- ADSR-огибающая
- Длительность ~1,5 с

### 8.4. Резонансное гудение

- Две синусоиды, интерференция, выход в стерео
- Громкость через стрелочный прибор

### 8.5. Скрытый апофатический пассаж

- Длинный вдох + медленный звон колокола
- Запускается только в скрытом режиме

### 8.6. Управление звуком

- Переключатель в пульте
- Респект `prefers-reduced-motion` (тихий режим)

---

## 9. Фаза «Пасхалки и скрытые режимы»

### 9.1. Апофатика

- Счётчик нажатий на «Спроецировать» при пустом вводе
- На седьмом нажатии — открытие чёрной комнаты с символом ∅

### 9.2. Телеграмма Бальтазарского

- С вероятностью 1% при загрузке Хроники — всплывает «свежая телеграмма»

### 9.3. Шифр на полях

- В подвале каждого модуля — короткая фраза
- При просмотре всех — собирается итоговый манифест
- Доступ к манифесту через специальную комбинацию клавиш

### 9.4. Звуковое завещание

- Таймер бездействия 3 мин
- Тихий акустический пассаж

---

## 10. Фаза «Доступность, устойчивость, полировка»

### 10.1. Доступность

- aria-атрибуты у всех интерактивных элементов
- Клавиатурная навигация по меню
- Минимум WCAG AA для основного текста
- Поддержка `prefers-reduced-motion`

### 10.2. Адаптивность

- Узкий экран: вертикальная компоновка, сворачиваемое меню
- Касания: увеличенные зоны нажатия

### 10.3. Оптимизация

- Ленивая генерация тяжёлых SVG
- requestAnimationFrame для canvas
- Debounce для поиска и ввода

### 10.4. Проверки и консистентность

- Согласованность данных между модулями
- Проверка всех пользовательских сценариев
- Проверка всех ссылок и перекрёстных связей

### 10.5. Финальная полировка

- Единый ритм паддингов и отступов
- Корректность всех микротекстов
- Отсутствие «висячих» заглушек

## 14. Критерии приёмки проекта

1. Ввод любого русского слова даёт осмысленную и стабильную выдачу
2. Все девять модулей переключаются плавно и без ошибок
3. Пользовательская эмотека сохраняется между сессиями
4. Звук можно выключить, анимации реагируют на `prefers-reduced-motion`
5. На мобильных устройствах интерфейс не ломается
6. Все заглушки заменены реальным контентом
7. Пасхалки работают и не мешают основному сценарию
8. Файл остаётся одним HTML-документом без внешних зависимостей помимо шрифтов
