Domain Coloring

Метод Domain Coloring использует цвет для представления значений комплексной функции f(z). Оттенок (hue) представляет аргумент числа (угол в полярной форме), а яркость представляет модуль. Раскраска происходит на комплексной плоскости, где оси X и Y соответствуют действительной и мнимой частям переменной z.

Справка по функциям комплексного переменного

Основы комплексных чисел

Комплексное число z = x + yi состоит из действительной части x и мнимой части y, где i - мнимая единица (i² = -1). Каждое комплексное число можно представить как точку на комплексной плоскости, где x - горизонтальная координата, а y - вертикальная координата.

Методы визуализации

Domain Coloring - метод, при котором каждой точке комплексной плоскости присваивается цвет, зависящий от значения функции f(z) в этой точке. Обычно оттенок (hue) представляет аргумент комплексного числа, а яркость - его модуль.

Конформные отображения - показывают, как функция f(z) трансформирует регулярную сетку на комплексной плоскости. Это позволяет увидеть, что функция сохраняет углы между кривыми (свойство конформности).

Векторные поля - представляют значение функции f(z) в виде векторов, где направление вектора соответствует аргументу, а длина - модулю значения функции.

Действительная и мнимая части - раздельное отображение Re(f(z)) и Im(f(z)) с использованием цветовой карты.

Работа с визуализатором

  • Введите функцию вручную или выберите шаблон из списка
  • Используйте колесико мыши для масштабирования
  • Перетаскивайте мышью для перемещения по плоскости
  • Наведите курсор на любую точку изображения, чтобы увидеть значения z и f(z)
  • Используйте кнопку "Сохранить изображение" для сохранения текущей визуализации

Популярные функции комплексного переменного

  • z² - квадратичная функция, поворачивает и растягивает комплексную плоскость
  • 1/z - обратная функция, превращает окружности в прямые
  • e^z - комплексная экспонента, периодична по мнимой оси
  • sin(z), cos(z) - комплексные тригонометрические функции
  • log(z) - комплексный логарифм, имеет разрез на отрицательной действительной оси
