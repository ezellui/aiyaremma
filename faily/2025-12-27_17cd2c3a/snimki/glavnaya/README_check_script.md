# Универсальный скрипт проверки философских связей

## Описание

Этот скрипт проверяет корректность обработки файлов с философскими связями, убеждаясь что:
1. Все связи из исходного файла обработаны
2. Исходные поля (source, target, type, weight, bidirectional) не изменены
3. Поле description добавлено ко всем связям
4. Не добавлено никаких лишних полей

## Использование

### Базовое использование

```bash
node check_relations_universal.js <исходный_файл> <обработанный_файл>
```

### Примеры

```bash
# Проверка первой порции связей
node check_relations_universal.js base_actual_r.js base_actual_r_with_descriptions.js

# Проверка второй порции
node check_relations_universal.js batch2_original.js relations_batch2_with_descriptions.js

# Проверка третьей порции
node check_relations_universal.js batch3_original.js relations_batch3_with_descriptions.js
```

## Формат входных файлов

Оба файла должны содержать JavaScript-массив `relations` с объектами связей:

```javascript
const relations = [
    { 
        source: "concept1", 
        target: "concept2", 
        type: "consequence", 
        weight: 3 
    },
    // ...
];
```

Обработанный файл должен иметь такую же структуру, но с добавленным полем `description`:

```javascript
const relations = [
    { 
        source: "concept1", 
        target: "concept2", 
        type: "consequence", 
        weight: 3,
        description: "Историко-философское описание связи..."
    },
    // ...
];
```

Количество связей:
  Исходный файл: 128
  Обработанный файл: 128

### При обнаружении проблем

Скрипт покажет детали всех найденных проблем:
- Список необработанных связей
- Поля, которые были изменены
- Связи без description
- Лишние добавленные поля

## Код возврата

- `0` - все проверки пройдены успешно
- `1` - обнаружены проблемы или произошла ошибка

Это позволяет использовать скрипт в автоматизированных процессах:

```bash
node check_relations_universal.js original.js processed.js
if [ $? -eq 0 ]; then
    echo "Проверка пройдена!"
else
    echo "Обнаружены ошибки"
fi
```

## Требования

- Node.js (любая современная версия)
- Файловая система с доступом к проверяемым файлам

## Примечания

- Скрипт использует `eval()` для извлечения массива relations, поэтому убедитесь, что файлы содержат только JavaScript-код
- Порядок связей в массивах не важен - скрипт находит соответствия по ключу (source + target + type)
- Поле `bidirectional` проверяется как часть исходных полей
