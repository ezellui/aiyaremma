## 🎯 Краткое описание

Это руководство содержит **полную интеграцию** всех философских метрик из файлов `philosophy_metrics.js` и `advanced_metrics.js` в ваш граф философских концепций.

### Что включено:

✅ **30+ метрик** - все метрики из обоих файлов  
✅ **Подробные описания** - с учётом параметров useWeightedPaths и respectDirection  
✅ **Визуализация размером** - для всех метрик  
✅ **Модальное окно** - в тёмной теме с эргономичной навигацией  
✅ **Полная интеграция** - чёткие инструкции, что удалить и что добавить

## 🎨 Ключевые особенности

### 1. Динамические описания метрик
Описания автоматически обновляются в зависимости от параметров:
- ✅ Учитываются ли веса связей
- ✅ Учитывается ли направленность

**Пример:**
```javascript
interpretation: () => {
    if (respectDirection && useWeightedPaths) {
        return "Направленный взвешенный: ...";
    } else if (respectDirection && !useWeightedPaths) {
        return "Направленный: ...";
    }
    // ...
}
```

### 2. Визуализация размером узлов
Для каждой метрики доступна кнопка "📏 Визуализировать размером":
- Размер узла = значение метрики
- Плавная анимация (500ms)
- Автоматическая настройка маркеров стрелок
- Функция сброса к оригинальным размерам

### 3. Синхронизация параметров
Переключатели в модальном окне синхронизируются с основными:
- Изменение в модальном окне → обновление глобальных переменных
- Автоматический перерасчёт при изменении параметров
- Сброс визуализации при изменении параметров

### 4. Эргономичная навигация
- Группировка метрик по категориям
- Активный пункт подсвечивается
- Прокрутка контента к началу при переключении
- Сохранение последнего просмотра при повторном открытии

## 🔧 Кастомизация

### Изменение цветовой схемы
В CSS измените градиенты:
```css
.stats-modal-content {
    background: linear-gradient(135deg, #1a1a2e 0%, #16213e 50%, #0f3460 100%);
}
```

### Добавление своей метрики
1. Добавьте метод в `PhilosophyGraphMetrics`:
```javascript
myCustomMetric(conceptId) {
    // ваша логика
    return { total: ... };
}
```

2. Добавьте описание в `metricDescriptions`
3. Создайте генератор `generateMyCustomMetricContent()`
4. Добавьте в навигацию и `loadStatsContent()`

### Экспорт результатов
Добавьте кнопку экспорта в генераторы:
```javascript
<button onclick="exportToCSV('${metricKey}')">
    💾 Экспорт в CSV
</button>
```

## 🐛 Отладка

### Модальное окно не открывается
✅ Проверьте Console (F12) на ошибки  
✅ Убедитесь, что `openStatsModal()` определена  
✅ Проверьте, что HTML модального окна добавлен

### Метрики не рассчитываются
✅ Убедитесь, что функции расчёта не были удалены  
✅ Проверьте, что `invalidateGraphCache()` существует  
✅ Посмотрите Console на ошибки при расчёте

### Описания не меняются при переключении параметров
✅ Проверьте, что описания используют функции, а не строки  
✅ Убедитесь, что `handleStatsParameterChange()` вызывается  
✅ Проверьте, что `loadStatsContent()` перезагружает контент

### Визуализация размером не работает
✅ Убедитесь, что `saveOriginalRadii()` вызвана  
✅ Проверьте, что данные метрики существуют  
✅ Посмотрите Console на ошибки D3.js

## 💡 Советы и рекомендации

### Производительность
- Философские метрики рассчитываются быстро (мгновенно)
