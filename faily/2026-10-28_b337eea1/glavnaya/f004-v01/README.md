# Корни слов нео-квэнья по данным Eldamo

`nq-roots.json` — каждое слово перечня [vocabulary-words-nq](https://eldamo.org/content/vocabulary-indexes/vocabulary-words-nq.html)
(Eldamo 0.8.13, 6060 слов: NQ. 2961, Q. 2058, ᴹQ. 1041) с корнем или набором корней.
Собирается из `eldamo-data.xml` за пару секунд, только стандартной библиотекой Python (подходит 3.8 на Windows 7):

```
python nq_roots.py путь/к/eldamo-data.xml nq-roots.json
python show.py nq-roots.json palantír alda miltë     # просмотр записей в одну строку
```

## Перечень слов

Тот же отбор, что в `vocabulary-index.xq` при `id=nq`: слова языков nq, q, mq (eq отсекается страницей),
без `<combine>`, `<deprecated>`, `<see>`, без имён, фраз, грамматики, фонетики и самих корней,
без `[unglossed]` и без `-` или `|` в `@mark`. Поле `spelling` — запись перечня (`c:normalize-spelling`: q → qu, k → c, конечное -e → -ë).

## Запись

```json
{
 "word": "tyallas", "spelling": "tyallas", "lang": "nq", "lang_name": "Neo-Quenya",
 "speech": "n", "gloss": "(playing) card", "url": "https://eldamo.org/content/words/word-1340155721.html",
 "rule": "elements",
 "roots": [
  {"form": "TYAL", "lang": "mp", "url": "…", "gloss": "play", "part": 0,
   "via": [{"rel": "element", "lang": "q", "form": "tyal-", "url": "…"},
           {"rel": "combine", "lang": "mq", "form": "tyal-", "url": "…"}]},
  {"form": "LAS¹", "lang": "p", "url": "…", "part": 1, "via": […]}
 ]
}
```

- `roots` — выбранные корни. Если у слова несколько частей (сложение), у корня есть `part`: корни с разными `part`
  складываются (√PAL + √TIR), корни с одним `part` — альтернативы (Q. alda: √GAL² / ᴹ√GALAD). Без `part` — все корни альтернативы одной части.
- `via` — цепочка от слова к корню: `element` (элемент), `deriv` (промежуточная форма), `combine` (то же слово
  другой концепции, слитое Eldamo), `see`, `deprecated`, `cognate`. Пустая цепочка — корень назван у самого слова.
- `same_as` — куда Eldamo сливает сам корень: цепочка его `<combine>` и нео-корень, под которым он записан
  (ᴹ√LUB² ≡ √LUB³ ≡ N√LUP). По последнему элементу удобно сводить корни разных периодов.
- `gaps` — части без корня на своих местах (Q. firya = √PHIR + -ya; суффиксы, слова без этимологии).
- `also` — корни из источников ниже рангом, которых нет среди выбранных; `rule` у каждого — откуда.
- `rule` — каким правилом выбраны корни; `uncertain` — если в цепочке есть `deprecated` или `cognate`.

Корни бывают поздние (`p`, 4943 вхождения), этимологические ᴹ√ (`mp`, 2142), нео (`np`, 389) и ранние ᴱ√ (`ep`, 161):
язык корня всегда указан — фильтруйте по нему, если нужны только поздние.

## Правила, по старшинству

1. **elements** — два и больше элемента с корнями: корни по частям. Элементы берутся у статьи, а если их нет —
   из одной её ссылки (с той же формой, иначе первой).
2. **deriv** — корни, названные деривациями слова: `<deriv>` статьи и `<deriv source>` внутри её ссылок (по `@source`,
   как `c:get-ref`). Корни, к которым ведёт промежуточная форма (✶galadā < ᴹ√GALAD), добавляются как альтернативы.
3. **element** — один элемент с корнем, остальные — пропуски.
4. **intermediate** — только через промежуточные формы (Q. lassë < ✶lassē < √LAS¹).
5. **combine** — через слова, слитые с этим (NQ. hlöa ← Q. hlöa < ✶(s)loga < √LOG).
6. **see** — через ссылку-заглушку.
7. **deprecated** — через слово, которое это заменило; принимается, только если оно начинается так же и согласные
   всех его корней есть в слове (ᴱQ. milt → NQ. miltë проходит; NQ. sin → latúcen, Q. engë → né, ᴱQ. nardilea → nisilëa — нет).
8. **cognate** — через когнаты (транзитивно, как раздел Cognates); только эльфийские языки, только корни, чьи
   согласные (не меньше двух) есть в слове; часть составного когната, не найденная в слове, — пропуск с `not_matched`.

Осторожности ради:

- когнаты не используются ниже самого слова (у элементов и промежуточных форм) — такие цепочки слишком свободны;
- корень когната попадает в `also`, только если и слово, и когнат несоставные: N. anrand (= ann + rand) не даёт
  ᴹQ. randa корень ᴹ√ANAD, S. dagnir не даёт Q. nehtar корень √N(D)ER;
- отвергнутое Толкином (`-` в `@mark`) не учитывается, если само слово не отвергнуто;
- праформы, записанные капителью, считаются корнями: в 0.8.13 N√GAWAK, ᴱ√ƷAWAKA и ᴱ√OWO размечены как существительные;
- циклы (Q. nelquë ↔ quainel) обрываются, результат детерминирован.

## Сверка с Quettamin

На тех же данных разрешение корней в `quettamin/shared/lexicon.py` совпадает для 5588 слов из 6060.
Остальное: у меня больше альтернатив (слияние прямой и промежуточной деривации, `combine`, `deprecated`) и нет корней,
которые Quettamin добавляет по совпадению записанной формы (ᴹ√AYA рядом с √AYA(N), ᴹ√ALA рядом с √AL(A)) — ссылка
`@source` той же деривации указывает на другой корень. Слов, где корень нашёл только Quettamin, нет.

535 слов без корня: в основном суффиксы, местоимения, частицы и слова, у которых Eldamo не даёт этимологии.
