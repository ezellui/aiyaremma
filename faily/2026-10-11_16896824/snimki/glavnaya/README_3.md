# Границы будущего — видео изменения границ на глобусе

Глобус с перелётами камеры между событиями выдуманной истории: страны и регионы admin-1 из согласованного
набора (`maps_extract/unified`), население — суммой по регионам, города Natural Earth.

```
pip install --break-system-packages numpy shapely pyproj rasterio pycairo pycountry   # + ffmpeg в системе
python3 prep.py        # один раз: кэш (растр регионов 8192×4096, дуги границ, русские названия, города)
python3 history.py     # проверить сценарий: что меняется, население и площадь новых государств
python3 render.py --plan                 # тайминг
python3 render.py --preview 200 860      # отдельные кадры в out/preview_*.png
python3 render.py --workers 2            # всё видео: out/future_borders.mp4 и out/future_borders.gif
```

## Сценарий (`scenario.json`)

```json
{
  "title": "...", "subtitle": "...", "start_year": 2030, "end_year": 2100,
  "intro": {"camera": [lon, lat, zoom], "text": "..."},
  "outro": {"camera": [lon, lat, zoom], "text": "..."},
  "note": "мелкая сноска в панели",
  "events": [ {"year": 2031, "title": "...", "text": "...", "camera": [lon, lat, zoom], "ops": [ ... ]} ]
}
```

`camera` — точка, куда смотрит камера, и приближение: при 1 весь глобус в кадре, ширина видимой
полосы ≈ 256°/zoom (3 — материк, 9 — Британия, 16 — Бельгия). Для приближений сильнее ~3 местная подробная
текстура строится сама.

Операции (`ops`), выполняются по порядку:

| op | поля | что делает |
|----|------|------------|
| `new_state` | `id`, `ru`, `short`?, `select`, `capital`? | новое государство из выбранных регионов |
| `join` | `into` (id), `select` | выбранные регионы переходят существующему государству |
| `rename` | `state`, `ru`, `short`?, `color`? | переименовать (и перекрасить) без смены границ |

`select` — любое сочетание:
- `"admins": ["Kenya", ...]` — целые страны по полю `admin` набора (английские имена Natural Earth);
- `"isos": ["GB-EDH", ...]` — отдельные регионы по коду ISO 3166-2;
- `"states": ["SCO", ...]` — государства, созданные раньше в сценарии (или исходные — по их `admin`).

`capital`: `{"ru": "Аруша", "lon": 36.67, "lat": -3.36}` — маркер и подпись столицы.
Идентификатор исходной страны — её `admin` (например, `"Antarctica"` в `rename`).
`history.py` печатает предупреждение, если какой-то `select` ничего не выбрал.

## Как устроен кадр

- Заливка: равнопромежуточный растр номеров регионов; цвет берётся из палитры текущего шага, переход между
  шагами — смешение двух палитр; на границах регионов — билинейное смешение. Озёра — водой.
- Границы, берега, подсветка меняющейся территории, города, подписи — векторами (cairo) поверх, поэтому
  остаются чёткими при любом приближении. Внутренние границы регионов проявляются при приближении.
- Цвета: приглушённая палитра, соседние государства различаются; новое государство получает цвет,
  отличный от соседей и от прежнего цвета своей территории.
- Население — сумма `pop` регионов из `regions_pop.json` (данные ≈2018, без прогноза).
