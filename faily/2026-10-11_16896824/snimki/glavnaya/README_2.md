# maps_extract

Границы стран и регионов admin-1 из `USER/html-generated/maps/data` в обычный GeoJSON.

```
pip install --break-system-packages shapely
python3 topo2geo.py <maps/data> out                 # все разрешения и слои, чистый планарный GeoJSON
python3 topo2geo.py <maps/data> out --res 10m --objects countries regions
python3 topo2geo.py <maps/data> out --raw           # без чистки: как в TopoJSON (соглашения d3)
```

## Что в исходнике

`world-110m.json`, `world-50m.json`, `world-10m.json` — TopoJSON (квантование 1e5 по осям, ≈ 400 × 190 м)
с данными Natural Earth. Объекты в каждом файле:

| объект    | 110m | 50m  | 10m  | свойства |
|-----------|------|------|------|----------|
| countries | 177  | 241  | 255  | `name` (краткое имя NE) |
| regions   | 4594 | 4594 | 4594 | `name`, `name_local`, `name_alt`, `admin` (страна), `iso_3166_2` |
| land, lakes, rivers, cities | ✓ | ✓ | ✓ | |

`regions_pop.json` — население по регионам; ключ `admin|name|name_local|iso_3166_2` (так его собирает `globe.html`).
Конвертер приклеивает к регионам `pop`, `pop_area_km2`, `pop_dens` — совпадают все 4594.

## Что делает чистка (по умолчанию)

- Кольца переводятся в порядок RFC 7946 (внешнее — против часовой). В исходнике — по часовой, как требует d3.
- Россия, Фиджи и Антарктида в слое стран пересекают ±180° одним отрезком: в плоской ГИС они легли бы полосой
  через весь мир. Они разрезаются по антимеридиану; кольцо Антарктиды замыкается через полюс.
- Самопересечения после квантования (их до 43 в `countries_10m`) исправляются `make_valid`, вырожденные обрезки убираются.

## Особенности данных

- Регионы во всех трёх файлах — одни и те же 4594 единицы, упрощённые с разной силой; даже `regions_10m`
  заметно грубее `countries_10m` (187 тыс. вершин против 545 тыс.). Поэтому внешние границы регионов и стран
  одного файла не совпадают в точности (в 10m расхождение ≈ 0,3 млн км² вдоль берегов и границ).
- В `countries_50m` у Антарктиды нет материка — только острова (так в самом исходнике).
- Ватикан как регион и как страна в 10m — с пустой геометрией.
- 7 регионов без имени; 20 ключей регионов повторяются (части одной единицы).
- `lakes`, `rivers`, `cities` в 50m и 10m одинаковы.
