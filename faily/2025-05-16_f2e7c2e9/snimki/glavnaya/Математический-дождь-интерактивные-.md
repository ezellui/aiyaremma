# Математический дождь: интерактивные математические фрагменты

Данная реализация расширяет проект "Шизография пред-языкового сознания" интерактивными математическими элементами. При клике на математический фрагмент запускается эффект "дождя" из сложных математических выражений по бокам экрана, сопровождаемый визуальной и звуковой обратной связью.

## Возможности

- Вертикальный "матричный" дождь из математических выражений при клике на формулы
- Сложные псевдоматематические формулы, имитирующие осмысленность
- Визуальная обратная связь с пульсирующими математическими символами
- Интеграция со звуковой системой проекта
- Визуальная эстетика, согласованная с общей концепцией проекта

## Код реализации

```javascript
// Функция для настройки эффекта математического дождя
function setupMathematicalRainEffects() {
    // Создаем стили для математического дождя
    const styleElement = document.createElement('style');
    styleElement.textContent = `
        .math-rain {
            position: absolute;
            top: 0;
            bottom: 0;
            width: 150px;
            overflow: hidden;
            pointer-events: none;
            z-index: 50;
        }
        #math-rain-left {
            left: 20px;
        }
        #math-rain-right {
            right: 20px;
        }
        .math-rain-drop {
            position: absolute;
            font-family: serif, "Times New Roman", math;
            white-space: nowrap;
            text-shadow: 0 0 8px rgba(150, 255, 255, 0.8);
            transform: translateX(-50%);
        }
        .math-element {
            cursor: pointer !important;
            transition: transform 0.3s cubic-bezier(0.175, 0.885, 0.32, 1.275), text-shadow 0.3s;
        }
        .math-element:hover {
            transform: scale(1.2) rotate(0deg) !important;
            z-index: 100 !important;
            text-shadow: 0 0 10px currentColor !important;
        }
        .pulsating-math-symbol {
            position: absolute;
            pointer-events: none;
            z-index: 100;
            font-family: serif, "Times New Roman", math;
        }
    `;
    document.head.appendChild(styleElement);
    
    // Создаем контейнеры для математического дождя
    const container = document.getElementById('container');
    
    // Левый контейнер
    const leftContainer = document.createElement('div');
    leftContainer.id = 'math-rain-left';
    leftContainer.className = 'math-rain';
    container.appendChild(leftContainer);
    
    // Правый контейнер
    const rightContainer = document.createElement('div');
    rightContainer.id = 'math-rain-right';
    rightContainer.className = 'math-rain';
    container.appendChild(rightContainer);
    
    // Переопределяем оригинальную функцию создания математических элементов
    const originalCreateMathElement = window.createMathElement;
    window.createMathElement = function() {
        const element = originalCreateMathElement();
        
        // Делаем элемент кликабельным
        element.style.pointerEvents = 'auto';
        element.addEventListener('click', handleMathElementClick);
        
        return element;
    };
    
    // Добавляем обработчики кликов на существующие математические элементы
    document.querySelectorAll('.math-element').forEach(element => {
        element.style.pointerEvents = 'auto';
        element.addEventListener('click', handleMathElementClick);
    });
}

// Обработка клика на математический элемент
function handleMathElementClick(event) {
    // Запускаем эффект матричного дождя
    triggerMathRain();
    
    // Воспроизводим звук, если аудио включено
    if (typeof audioContext !== 'undefined' && typeof audioEnabled !== 'undefined' && audioEnabled) {
        // Создаем параметры для звука
        const pitch = 1.2 + Math.random() * 0.8;
        const volume = 0.25 + Math.random() * 0.15;
        const pan = (event.clientX / window.innerWidth) * 2 - 1;
        
        // Воспроизводим звук, если функция существует
        if (typeof playSound === 'function' && typeof soundLibrary !== 'undefined') {
            playSound(soundLibrary.buffers.mathElements, pitch, volume, pan, 3.0);
        }
        
        // Создаем визуализацию звука, если функция существует
        if (typeof createSoundVisualization === 'function') {
            createSoundVisualization(
                event.clientX, 
                event.clientY, 
                `hsl(${Math.floor(200 + Math.random() * 40)}, 80%, 65%)`, 
                1.2
            );
        }
    }
    
    // Создаем пульсирующий математический символ
    createPulsatingMathSymbol(event.clientX, event.clientY);
}

// Генерация сложных математических выражений
function generateComplexMathExpression(length) {
    // Получаем все доступные математические символы из контекста страницы
    const allSymbols = [];
    
    // Используем существующий объект mathSymbols, если доступен
    if (typeof mathSymbols !== 'undefined') {
        // Объединяем все категории символов в один массив
        for (const category in mathSymbols) {
            if (Array.isArray(mathSymbols[category])) {
                allSymbols.push(...mathSymbols[category]);
            }
        }
    } else {
        // Резервные символы, если mathSymbols недоступен
        allSymbols.push(
            // Греческие буквы
            'α', 'β', 'γ', 'δ', 'ε', 'ζ', 'η', 'θ', 'λ', 'μ', 'ν', 'ξ', 'π', 'ρ', 'σ', 'τ', 'φ', 'χ', 'ψ', 'ω',
            // Операторы и множества
            '+', '-', '×', '÷', '=', '≠', '≈', '∑', '∏', '∫', '∂', '∇', '√', '∞', '∈', '∉', '⊂', '⊃', '∩', '∪',
            // Разделители
            '(', ')', '[', ']', '{', '}', '|', '‖',
            // Переменные
            'x', 'y', 'z', 'f', 'g', 'n', 'm'
        );
    }
    
    // Специальные полные математические выражения
    const specialExpressions = [
        '∫ f(x) dx', '∑_{i=1}^{∞}', '∂²f/∂x²', 'lim_{x→∞}',
        '∇×F', '∇·F', 'Δf', 'e^{iπ}+1=0', '√{x²+y²}',
        'a_{n+1} = a_n + a_{n-1}', 'f: X → Y', '||v||',
        'det(A-λI) = 0', 'x ∈ ℝ', '∀ε>0 ∃δ>0',
        '⟨ψ|H|ψ⟩', 'P(A∩B|C)', '∮ E·dl = -∂Φ_B/∂t',
        'ds² = g_{μν}dx^μdx^ν', '∇²ψ + k²ψ = 0',
        'ψ(x,t) = Ae^{i(kx-ωt)}', 'F = G(m₁m₂)/r²',
        'E = mc²', 'S = k·ln(W)', 'i\u0127 ∂ψ/∂t = Ĥψ'
    ];
    
    // Генерируем случайное выражение
    let expression = '';
    
    // Начинаем со специального выражения с вероятностью 70%
    if (Math.random() < 0.7) {
        expression = specialExpressions[Math.floor(Math.random() * specialExpressions.length)];
    }
    
    // Добавляем символы до достижения нужной длины
    while (expression.length < length) {
        // Иногда добавляем ещё одно специальное выражение
        if (Math.random() < 0.3 && expression.length < length - 10) {
            expression += ' ' + specialExpressions[Math.floor(Math.random() * specialExpressions.length)];
        } else {
            // Добавляем случайный символ, иногда с пробелом
            expression += (Math.random() < 0.2 ? ' ' : '') + allSymbols[Math.floor(Math.random() * allSymbols.length)];
        }
    }
    
    return expression;
}

// Создание пульсирующего математического символа
function createPulsatingMathSymbol(x, y) {
    // Сложные математические символы
    const complexSymbols = [
        '∫', '∑', '∏', '√', '∂', '∇', 'Δ', 'Ω', 'λ', 'φ', '∞', 'π', 
        '⊕', '⊗', '⊂', '⊃', '∩', '∪', '⇒', '⇔', '∀', '∃', '≡', '≈'
    ];
    
    // Создаем элемент
    const symbol = document.createElement('div');
    symbol.className = 'pulsating-math-symbol';
    symbol.textContent = complexSymbols[Math.floor(Math.random() * complexSymbols.length)];
    symbol.style.left = x + 'px';
    symbol.style.top = y + 'px';
    symbol.style.transform = 'translate(-50%, -50%)';
    symbol.style.fontSize = '5rem';
    symbol.style.color = `hsl(${Math.floor(180 + Math.random() * 60)}, 80%, 70%)`;
    symbol.style.opacity = 0;
    symbol.style.textShadow = `0 0 15px ${symbol.style.color}`;
    symbol.style.transition = 'all 0.3s cubic-bezier(0.175, 0.885, 0.32, 1.275)';
    
    document.getElementById('container').appendChild(symbol);
    
    // Анимация
    setTimeout(() => {
        symbol.style.opacity = 1;
        symbol.style.transform = 'translate(-50%, -50%) scale(1.5)';
        
        setTimeout(() => {
            symbol.style.opacity = 0;
            symbol.style.transform = 'translate(-50%, -50%) scale(3)';
            
            setTimeout(() => {
                if (symbol.parentNode) {
                    symbol.parentNode.removeChild(symbol);
                }
            }, 500);
        }, 800);
    }, 50);
}

// Создание одной капли математического дождя
function createMathRainDrop(container, baseHue) {
    // Создаем элемент
    const drop = document.createElement('div');
    drop.className = 'math-rain-drop';
    
    // Позиция - рандомизируем координату X
    drop.style.left = Math.random() * 100 + '%';
    drop.style.top = '-100px';
    
    // Оформление
    const hue = baseHue + (Math.random() * 30 - 15);
    const color = `hsl(${hue}, 70%, 70%)`;
    drop.style.color = color;
    drop.style.fontSize = (1 + Math.random() * 1.5) + 'rem';
    drop.style.textShadow = `0 0 5px ${color}`;
    drop.style.opacity = 0.8;
    
    // Содержание - генерируем сложное математическое выражение
    drop.textContent = generateComplexMathExpression(10 + Math.floor(Math.random() * 20));
    
    // Добавляем в контейнер
    container.appendChild(drop);
    
    // Параметры анимации
    const duration = 5000 + Math.random() * 10000; // 5-15 секунд
    const containerHeight = container.offsetHeight || window.innerHeight;
    
    // Настраиваем переход
    drop.style.transition = `top ${duration}ms linear, opacity 2000ms`;
    
    // Запускаем анимацию после небольшой задержки
    setTimeout(() => {
        drop.style.top = containerHeight + 'px';
        
        // Удаляем после анимации
        setTimeout(() => {
            drop.style.opacity = 0;
            setTimeout(() => {
                if (drop.parentNode) {
                    drop.parentNode.removeChild(drop);
                }
            }, 2000);
        }, duration - 2000);
    }, 50);
    
    return drop;
}

// Запуск математического дождя
function triggerMathRain() {
    const leftContainer = document.getElementById('math-rain-left');
    const rightContainer = document.getElementById('math-rain-right');
    
    if (!leftContainer || !rightContainer) return;
    
    // Настраиваем параметры
    const baseHue = Math.floor(180 + Math.random() * 60); // Сине-голубой оттенок
    const intensity = 15 + Math.floor(Math.random() * 10); // Количество капель
    const duration = 8000; // Общая продолжительность в мс
    
    // Генерируем начальные капли
    for (let i = 0; i < intensity / 3; i++) {
        createMathRainDrop(leftContainer, baseHue);
        createMathRainDrop(rightContainer, baseHue);
    }
    
    // Генерируем ещё капли со временем
    let elapsed = 0;
    const interval = 300; // Новая капля каждые 300мс
    
    const rainInterval = setInterval(() => {
        elapsed += interval;
        if (elapsed >= duration) {
            clearInterval(rainInterval);
            return;
        }
        
        createMathRainDrop(leftContainer, baseHue);
        createMathRainDrop(rightContainer, baseHue);
    }, interval);
}

// Инициализация при загрузке страницы или немедленно, если документ уже загружен
if (document.readyState === 'loading') {
    window.addEventListener('DOMContentLoaded', setupMathematicalRainEffects);
} else {
    setupMathematicalRainEffects();
}
```

## Интеграция

1. Добавьте этот код в раздел JavaScript HTML-файла, предпочтительно в конце тега `<script>`.
2. Код автоматически инициализируется при загрузке страницы.
3. Существующие математические элементы станут кликабельными, а новые будут иметь встроенное поведение при клике.

## Пояснение

### Настройка контейнеров

Реализация создаёт два вертикальных контейнера по левому и правому краям экрана для размещения падающих математических выражений.

### Генерация математических выражений

Сложные математические выражения генерируются с использованием как случайных символов, так и предопределённых формул, имитирующих осмысленность, например:
- ∫ f(x) dx
- ∑_{i=1}^{∞}
- ∂²f/∂x²
- e^{iπ}+1=0
- ψ(x,t) = Ae^{i(kx-ωt)}

Это создаёт визуально интересный эффект, имитирующий осмысленное математическое содержание.

### Визуальная обратная связь

При клике на математический элемент:
1. В месте клика появляется пульсирующий математический символ
2. По обеим сторонам экрана начинает падать дождь из выражений в стиле "Матрицы"
3. Создаётся визуализация звука (если аудио включено)

### Интеграция звука

Реализация интегрируется с существующей аудиосистемой для воспроизведения звуков при клике на математические элементы, используя существующие функции `playSound` и `soundLibrary`.

### Стилизация

Визуальный стиль использует сине-голубую цветовую палитру, чтобы отличаться от языковых выражений, сохраняя при этом общую эстетику проекта.

## Настройка эффекта

Вы можете настроить следующие параметры для кастомизации эффекта:
- `baseHue`: Изменение цветовой схемы (180-240 для сине-голубого)
- `intensity`: Количество выражений в дожде (больше = плотнее)
- `duration`: Как долго появляются новые капли (дольше = более продолжительный эффект)
- Размеры шрифта и продолжительность анимации в функции `createMathRainDrop`
